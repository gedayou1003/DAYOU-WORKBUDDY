## 一、拟合层：13 个融合点，数据到底替我们否决了什么、确认了什么

「拟合」不是把结论背下来，而是让回测当**试金石**，把「空话」和「真话」分开。9/24 那轮拟合，最有信息量的不是谁涨谁跌，而是下面这些**证伪**：

| 拟合事实 | 数字 | 它否决了什么 |
|---|---|---|
| 六态 → 次日方向 | 全部落在 50%±10% | 否决「六态能直接择时」 |
| 两种「极强」口径 | 价格加速口径**偏跌** / MACD 六态口径**偏涨** | 否决「极强」是一个单一概念 |
| 主涨段 → 5 日新高 | 56.5% vs 60.6%（无增量） | 否决「主涨段是短线信号」 |
| 集中度 → 次日/5 日 | 方向**反向** | 否决「行业成交额近似资金抱团」 |
| 二次跌破 → 5 日仍跌 | 45.8% < 50% | 否决「解除 = 转空」 |

**被确认的（有增量）只有三处**：主涨段→创 20 日新高（+12.5pp）、尾指数→极端下跌预警（6.2 倍）、顶背离在**非极强**下看空（62.5%）。注意它们三个的共同点，见下。

## 二、参悟层：从「否决了什么」反推方法论的三条真谛

### 真谛一：这套方法论的「魂」是消除歧义，不是任何单个结论

两条相反口径的「极强」，是整轮拟合里最漂亮的一个结果。它说明：作者用 `DIF≥0 且 DEA≤0 且 MACD>0` 把「极强」**钉到符号级**，才让「同一句话能推出两个相反结论」这件事暴露出来——而不是继续用「涨得快」这种模糊词糊弄过去。

**参悟**：市场里绝大多数「有用的话」（强者恒强、极强看空、均值回归……）之所以没用，不是话错了，是**话没定义**。定义到符号级，回测就能证伪它；证伪剩下的那点真东西，才是可积累的。**这套方法论真正可迁移的，是「把模糊概念定义到可回测、可证伪」这一套操作**——它跟这周我在代码里踩的坑（退出码 0/1/2 不能用布尔、pending 目标日要查节假日、极强两种口径要拆字段）是**同一个病根、同一种解法**，区别只在他用交易语言讲、我用代码语言讲。

### 真谛二：它所有「有增量」的地方，都不是「方向」，是「结构 + 风险」

三个被确认的增量，性质高度一致：
- 主涨段 → 预测「**中期新高**」（结构确认，非涨跌）
- 尾指数 → 预测「**极端下跌概率**」（风险预警，非涨跌）
- 顶背离 → 只在「非极强」下看空（**状态条件**，非无条件方向）

**参悟**：这套方法论的输出是「**现在处于什么结构、风险有多大**」，不是「明天往哪走」。它的正确姿势是当**字典 + 体检表**，不是择时神器。谁拿它赌方向，谁必失望——这也解释了为什么星球里很多人读完觉得「有用但说不清用在哪」。

### 真谛三：两套级差、两种极强并存 = 承认市场多尺度，拒绝形而上学

作者原文明说「级差体系有两套，有时相互穿插影响，需要具体问题具体分析，不能太形而上学」。这不是他含糊，是**他诚实**：市场同时存在 3F-15F-60F-日（标准缠论级差）和 1F-5F-30F-120F（2.5 倍级差）两套尺度，且会互相影响。

**参悟**：一个「敢说不能太形而上学」的方法论，比一个「每句话都斩钉截铁」的玄学可靠得多。**它教的是「用符号逼近，但知道逼近有边界」**——这跟回测里「n=23 样本不足、只作参考标注」是一脉相承的诚实。

## 三、真谛层：一句话

> **定调五篇论文真正教的不是「怎么赚钱」，而是「怎么把一个模糊的市场概念，定义到能被回测证伪的精确程度」；在这个过程里幸存下来的、定义清晰且回测有增量的东西，几乎全都是「结构与风险」，没有一个纯粹的方向信号。**

所以「找到真谛」不是找到一个圣杯公式，而是**练会了「拟合 → 证伪 → 留下真东西」这套动作**。动作本身，就是真谛。

## 四、与现有体系的融合定位（一句话版）

它是**语义校准层**，不是新引擎：X段≈缠论「段」、55线≈现有 MA55 关键位、六态≈ MACD 多空区的精细化。融合姿势 = 拿它当字典去校准缠论+BOLL，产出挂「关键位 / 参考标注 / risk_note」，**不碰方向打分**。
