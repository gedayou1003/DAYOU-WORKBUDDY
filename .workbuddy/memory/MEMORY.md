### 1. "相反观点"章节强制校验（2026-08-19 事故复盘后建立）
写"跨星球观点对比 → 相反观点"时，必须通过三步自检，缺一不可：
1. **方向断言**：左右两列各写一个方向标签（如"看多油价"vs"看空油价"），标签必须互斥；若两列标签相同 → 不是相反观点，移到"共同观点"或"隐含共识"
2. **资产维度**：判断对立的标准是"对同一资产/标的的价格影响方向"，不是消息本身的情绪好坏
3. **回扫遗漏**：写完后再回看原始抓取内容，确认真正的对立面没有被漏掉
教训案例：2026-08-19 晨报"油价/伊朗局势"行左右两列都是"地缘紧张→利好油价"，归类错误

### 6. 技术预判链机制（2026-08-21 并入三档自动化）
- 核心思路：每个报告时段基于多口径（引擎A多维/引擎B买卖点/BOLL×缠论/星球观点）给出"综合预判"（方向/区间/支撑/压力/置信度），下一时段用实际 OHLC 复盘，只记录差异、不做优化
- 存储文件：`.workbuddy/forecast_chain.json`
- 实际走势获取：`.workbuddy/get_daily_ohlc.py`
- 验证配对：晨报9:00→验证前一日16:00；午间12:30→验证晨报；收盘后16:00→验证午间；晚间19:00→验证晨报
- 预判对象：晨报=今日全天、午间=下午（13:00-15:00）、收盘后=次日
- 复盘判定：✅命中 / ⚠️部分 / ❌相反
- **偏差归因与统计**：①找原因 ②判断可预料性 ③打偏差标签 bias_type ④统计积累（读 forecast_chain.json 所有已复盘 review.bias_type 频率，某标签 ≥3 次 → 标注「规律已现」供观察）
- **统计信号仅观察、不修改**（用户核心原则）：改一处可能引发新的连锁反应，形成"改→新问题→再改"的奇怪循环；先继续观察积累样本
- **口头触发词**："预判一下走势"等类似表述时，直接执行预判分析流程（取OHLC→跑引擎→读/写 forecast_chain.json→输出预判结论）
- **预判结论必须带百分比**：关键位相对现价标注涨跌百分比（如 +0.64% / -0.49%），配"预判走势图"（SVG：上午实线已走路径 + 下午两种剧本虚线，红涨绿跌）
- **术语英文化**：H/L/O/C、Resist/Supp、Bullish/Bearish/Sideways(Range-bound)、Confidence、Trend；缠论术语（笔/中枢/买卖点）保留中文
- **预判走势图标记全英文 + 缩写**：Resistance→RESIST、Support→SUPP、Bullish→BULL、Bearish→BEAR、Sideways→SIDE
- **预判图 y 轴映射铁律**：价格越高 y 越小，公式 `y = 底部 - (价格-最低价)/价差*图高`，绝不能写 `y=价格*比例`
- **多口径权重合成 + 置信度打分**：综合预判按各口径信号强弱+方向一致性加权合成，最后给置信度打分（低/中/高）。分工：①缠论多级别 + BOLL×缠论 + 区间套 → 定"区间 + 关键位"②星球观点 → 定"方向的强弱"③综合得"方向/区间/支撑/压力/置信度"
- **预判客观因素补充**（2026-08-23 T&J 周度思考启发；用户要求纳入分析逻辑、引擎参数不动）：
  1. **时间维度/事件风险**：重要事件（Jackson Hole、FOMC、领导人会面、财报季、重大数据）未落地前置信度应下调
  2. **宏观权重**：宏观主导阶段（美债/Warsh/利率失控），技术面权重下调、宏观方向权重上调
  3. **级别视角/尾部风险**：不能只看小级别买卖点，须检查大级别（周线）结构是否完整；若大级别下跌结构未完成，须把"新低下杀"作为尾部风险剧本纳入

### 9.4 模型硬伤诊断 + 补救（2026-08-24，用户要求"补硬伤→进步"）
- **3 处结构性硬伤**（非参数问题）：
  1. 方向判断缺「方向不明」状态 + 无趋势因子 → 变盘临界硬猜方向，方向相反率 52.6%
  2. 支撑/压力用「单点买卖点」且缺失时无兜底 → 区间覆盖仅 10.5%
  3. 买卖点信号无「变盘抑制」 → 信号滞后成反向指标
- **补救后净进步**（v1→v4 回测验证）：
  - 方向相反率 **52.6% → 36.8%**（-15.8pct）
  - 区间覆盖率 **10.5% → 31.6%**（3 倍）
  - 支撑守住率 **10.5% → 68.4%**（6.5 倍）
  - 方向命中率 31.6% → 36.8%
- **补救具体做法**：①方向打分加日线/周线趋势因子（向上+2/向下-2）；②|总分|≤1 或 15F BOLL 带宽<1% 极度收口 → 输出「方向不明」不硬猜；③支撑/压力买卖点价位 ±0.5% 区间带；④无买卖点时用 15F BOLL 下轨/上轨兜底支撑/压力。
- **关键反直觉发现**：T&J 方向校准「适得其反」——虽然 T&J 整体准确率 47.4% > 引擎 31.6%，但「方向不明时用 T&J 硬猜方向」把相反率打回 52.6%。**正确用法：方向不明就保持方向不明（规避），T&J 仅作参考标注、不替代判断。**
