## 一、报告写作规范

### 1. "相反观点"三步自检（2026-08-19 事故后强制）
1. **方向断言**：左右两列各写互斥方向标签（如"看多"vs"看空"）；标签相同 → 不是相反观点，移入共同观点/隐含共识
2. **资产维度**：对立标准 = 对同一资产/标的的价格影响方向，非消息情绪好坏
3. **回扫遗漏**：写完回看原始抓取，确认真对立面没漏
教训：2026-08-19 晨报"油价/伊朗局势"两列都是"地缘紧张→利好油价"，归类错误。

### 2. 报告匿名化 + 改进版格式（2026-08-21 起只产改进版一份）
- 正文直接表达观点不标来源代号；通道信息放文末附录 A；代号对照放附录 B

- 产物：`000001_YYYYMMDD_BOLL缠论交叉验证.md` + json

### 6. 技术预判链（三档自动化核心）
- 文件：`.workbuddy/forecast_chain.json`；OHLC 获取：`.workbuddy/get_daily_ohlc.py`
- 验证配对：晨报(8:30)→验证前一日收盘预判；午间(12:30)→验证晨报；收盘(16:00)→验证午间
- 预判对象：晨报=今日全天、午间=下午、收盘=次日；复盘判定 ✅/⚠️/❌
- **偏差归因与统计**：找原因→判可预料性→打 bias_type 标签→统计频率（≥3 次仅标注「规律已现」供观察，**绝不修改策略**——改一处可能引发连锁反应）
- **预判输出规范**：关键位带相对现价百分比；术语英文化（H/L/O/C、RESIST/SUPP、BULL/BEAR/SIDE、Scenario A/B，缠论术语保留中文）；SVG 走势图实线=已走路径+虚线=两剧本，红涨绿跌；**y 轴铁律：`y = 底部 - (价格-最低价)/价差*图高`，绝不能 y=价格*比例**
- **多口径合成**：缠论多级别+BOLL+区间套→区间与关键位；星球观点→方向强弱；综合→方向/区间/支撑/压力/置信度
- **客观因素补充**（2026-08-23 T&J 启发，引擎参数不动）：①重要事件未落地前置信度下调 ②宏观主导阶段技术权重下调 ③须查大级别（周线）结构，下跌未完成须纳入"新低下杀"尾部风险 ④缩量+题材化阶段技术信号易把"跌不动的反抽"误读为偏多
