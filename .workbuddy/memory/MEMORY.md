### 1. "相反观点"章节强制校验（2026-08-19 事故复盘后建立）
写"跨星球观点对比 → 相反观点"时，必须通过以下三步自检，缺一不可：
1. **方向断言**：为左右两列各写一个方向标签（如"看多油价"vs"看空油价"、"偏多大盘"vs"偏空大盘"），标签必须互斥；若两列标签相同 → 不是相反观点，移到"共同观点"或"隐含共识"
2. **资产维度**：判断对立的标准是"对同一资产/标的的价格影响方向"，不是消息本身的情绪好坏（坏消息A vs 坏消息B 不等于相反；利多 vs 利空才是相反）
3. **回扫遗漏**：写完后再回看原始抓取内容，确认真正的对立面没有被漏掉（本次事故即漏掉了卫斯李 20:01"油价极端右尾风险有限/政策应对"与 08:14"TACO 缓和概率高"的真相反，却用同向的 07:32 凑数）
教训案例：2026-08-19 晨报 3.2 "油价/伊朗局势"行，左右两列都是"地缘紧张→利好油价"（左：暂停谈判/遭导弹；右：局势未缓和/WTI 三连涨），归类错误，已修正。

### 6. 技术预判链机制（2026-08-21 新增，已并入三档自动化 9:00/12:30/16:00）
- **核心思路**：每个报告时段基于多口径（引擎A多维/引擎B买卖点/BOLL×缠论/星球观点）给出"综合预判"（方向/区间/支撑/压力/置信度），下一时段用实际 OHLC 复盘，只记录差异、不做优化（市场存在偶然性与反身性，先积累样本再研究）
- **存储文件**：`.workbuddy/forecast_chain.json`（记录数组，含 direction/range/support/resistance/confidence/evidence/summary/status/review）
- **实际走势获取**：`.workbuddy/get_daily_ohlc.py`（腾讯 fqkline 日线，返回当日 OHLC + 涨跌幅）
- **验证配对**：晨报9:00→验证前一日16:00"次日预判"（开盘初验）；午间12:30→验证晨报"今日预判"（上午走势）；收盘后16:00→验证午间"下午预判"（当日完整收盘验证）
- **预判对象**：晨报=今日全天、午间=下午（13:00-15:00）、收盘后16:00=次日
- **报告章节**：各报告末尾新增 `## 技术预判与复盘`（上期复盘表 + 本期预判）
- 复盘判定：✅命中 / ⚠️部分 / ❌相反，只指出偏差与可能原因假设
- **偏差归因与统计（2026-08-21 用户要求）**：复盘时①找原因（预判与实际差在哪项、差多少）②判断可预料性（可预料-技术信号固有局限 / 不可预料-消息面突发 / 部分可预料）③打偏差标签 bias_type（如"压力位短暂突破""支撑精准未触及""方向正确区间偏移""消息面突发打乱技术结构""三买信号延迟确认"）④统计积累（读 forecast_chain.json 所有已复盘 review.bias_type 频率，某标签 ≥3 次 → 标注「规律已现：该现象反复出现，可能对应某种稳定技术逻辑」，附历史案例）。字段写入 review：bias_type / foreseeable / foresee_reason
- **统计信号仅观察、不修改（2026-08-21 用户核心原则）**：即使出现统计意义信号（某偏差标签 ≥3 次、某共识反复命中），也**只标注观察，不急着修改策略/逻辑/参数**。原因：改一处可能引发新的连锁反应（A 改了 B 又变），形成"改→新问题→再改"的奇怪循环；且市场有反身性（自身行为改变市场）与过拟合风险。正确节奏：发现→记录→继续观察→样本足够且多重验证后，才考虑调整。所有复盘、共识复盘、偏差统计都遵循此原则。
- **口头触发词（2026-08-21 用户约定）**：用户说"预判一下走势"（或"预判""走势怎么看""接下来怎么走"等类似表述）时，**直接**执行预判分析流程：①跑 get_daily_ohlc.py 取最新 OHLC ②跑 chan-signal 引擎刷新买卖点（必要时加 BOLL×缠论）③读/写 forecast_chain.json（先复盘上期 pending，再写本期）④输出"方向/区间/支撑/压力/置信度/依据"的预判结论。不需要用户再解释流程，无需多轮确认，给完即止。
- **预判结论必须带百分比**（2026-08-21 用户要求）：关键点位相对现价标注涨跌百分比（如 +0.64% / -0.49%），并配一张"预判走势图"（SVG：上午实线已走路径 + 下午两种剧本虚线，红涨绿跌）
- **术语英文化（2026-08-21 用户要求）**：关键位与 OHLC 用专业英文，缠论术语（笔/中枢/买卖点）保留中文。术语对照表：
  - 最高 High(H) / 最低 Low(L) / 开盘 Open(O) / 收盘 Close(C)
  - 压力 Resistance / 支撑 Support
  - 方向 Direction：偏多 Bullish / 偏空 Bearish / 震荡 Sideways(Range-bound)
  - 区间 Range / 置信度 Confidence / 趋势 Trend
  - 一买 B1 / 二买 B2 / 三买 B3；一卖 S1 / 二卖 S2 / 三卖 S3
- **预判走势图标记全英文 + 缩写**（2026-08-21 用户要求）：SVG 图上所有标记用英文缩写，避免文字重叠。缩写规范：Resistance→RESIST、Support→SUPP、Bullish→BULL、Bearish→BEAR、Sideways→SIDE、Weekly→W、Session High/Low→Day H/L；价格轴范围约 160 点（1.5x 平缓缩放），红涨绿跌不变
- **预判图 y 轴映射铁律**（2026-08-21 事故教训）：SVG 里 y 值越大越靠下，所以**价格越高 y 必须越小**（上=高价、下=低价）。映射公式 `y = 底部 - (价格 - 最低价)/价差 * 图高`，绝不能写成 `y = 价格 * 比例`（会上下颠倒，上涨路径画成下降）。曾把 A·Bull 上涨剧本画反被用户指出，已修正。
- **预判方法：多口径权重合成 + 置信度打分（2026-08-21 用户认可并定为约定）**：综合预判不靠单一信号拍脑袋，而是把各口径（引擎A多维/引擎B买卖点/BOLL×缠论/区间套/星球观点）按"信号强弱 + 方向一致性"加权合成，最后给一个置信度打分（低/中/高）。分工：①缠论多级别 + BOLL×缠论 + 区间套 → 定"区间 + 关键位"②星球观点 → 定"方向的强弱"（多空分歧则压向震荡、一边倒则强化单边）③综合得"方向/区间/支撑/压力/置信度"，并在依据里拆解每个口径的具体贡献。好处：避免单一信号的决策不确定性，结论可追溯、可复盘。
