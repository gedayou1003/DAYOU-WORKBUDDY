# 预判规则 v5（2026-08-24 回测验证后固化）

## 一、演进脉络

- **v1 原版**：方向主观拍脑袋 + 支撑/压力单点买卖点 → 方向相反率 52.6%、区间覆盖 10.5%
- **v4**：方向量化打分 + 方向不明 + 区间带 + BOLL 兜底 → 方向相反率 36.8%、区间覆盖 31.6%
- **v5**：支撑/压力升级为「55 线优先」（T&J 的 MA55 关键位理论）→ 区间覆盖 48%（60F 版）

## 二、v5 预判规则（4 条）

### 1. 方向量化打分（替代主观拍脑袋）
- **趋势因子**：日线/周线 `current_trend`（向上 +2 / 向下 -2 / 未知 0）
- **买卖点因子**：各周期 20 天内近期信号加权——日线 ±2 / 周线 ±2 / 60F ±2 / 15F ±1（买点 + / 卖点 -）
- **总分**：≥3 → 偏多；≤-3 → 偏空；|总分|≤1 → 方向不明；其余 → 震荡（按 15F 信号微调偏多/偏空）

### 2. 「方向不明」状态（方向相反率 -15.8pct 的主要来源）
- 触发条件：|总分| ≤ 1（多空平衡）**或** 15F BOLL 带宽 < 1%（极度收口变盘在即）
- 输出「方向不明」，**不硬猜方向**，给 A/B 双向剧本

### 3. 支撑/压力（v5：55 线优先，核心升级）
- **支撑** = 下方最近的 **55 线**（日线55 / 60F55 / 15F55 中低于现价的最高值）
- **压力** = 上方最近的 **55 线**（高于现价的最低值）
- **55 线缺失时** → 近期买点当支撑 / 近期卖点当压力
- **再无** → 15F BOLL 下轨当支撑 / 上轨当压力
- 各带 **±0.5% 容差**，标注为区间带（如「支撑 3884±19」）而非精确单点

### 4. 方向与关键位分离（重要原则）
- **方向**：用大级别（日线/周线趋势 + 买卖点）
- **关键位（支撑/压力）**：用 55 线 + 买卖点 + BOLL，三者兜底

## 三、MA55（55 线）回测关键发现

### T&J 的 55 线「准」在关键位，不在方向

| 维度 | 用法 | 结果 | 结论 |
|---|---|---|---|
| 方向信号 | 站上/跌破 55 线判断多空 | 相反率 36.5% | ❌ 不如买卖点 29.8% |
| **关键位** | 55 线作为支撑/压力 | **区间覆盖 79.6%** | ✅ 远优于买卖点 38.6% |

- 60F 版区间（188 样本）：55 线框住次日走势成功率 **79.6%** vs 买卖点 **38.6%**（差一倍多）
- 这解释了 T&J 整体方向准确率（47.4%）高于引擎（31.6%）——**关键位准带动了整体胜率**

### 结论
**MA55 是「关键位」工具，不是「方向」工具**。所以 v5 把它接在「支撑/压力」维度，方向判断原样不动。

## 四、关键反直觉发现 ⚠️

**T&J 方向校准「适得其反」**：
- T&J 整体方向准确率 47.4% > 引擎 31.6%，看似该用来校准
- 但「方向不明时用 T&J 硬猜方向」把相反率从 36.8% 打回 52.6%（v3 回测验证）
- **正确用法**：方向不明就保持「方向不明」（规避），T&J 仅作**参考标注**、不替代判断

## 五、仍未解决（诚实说明）

1. 方向相反率仍约 28~30%——缠论买卖点是"已发生转折"的结构类信号，趋势反转初期天然滞后，靠"变盘信号前置预警"（带宽收口、日线零轴金叉/死叉）逐步改善。
2. 区间带 ±0.5% 为经验值。
3. 15F 信号在方向判断里可能是"噪音"（日线版相反率 29.8% 低于 15F 版 36.8%），方向判断或以大级别为主更优——待进一步确认。
