## 一、演进脉络

- **v1 原版**：方向主观拍脑袋 + 支撑/压力单点买卖点 → 方向相反率 52.6%、区间覆盖 10.5%
- **v4**：方向量化打分 + 方向不明 + 区间带 + BOLL 兜底 → 方向相反率 36.8%、区间覆盖 31.6%
- **v5**：支撑/压力升级为「55 线优先」（DRAGON BALL模型 的 MA55 关键位理论）→ 区间覆盖 48%（60F 版）

## 二、v5 预判规则（4 条）

### 1. 方向量化打分（替代主观拍脑袋）
- ~~**趋势因子**：日线/周线 `current_trend`（向上 +2 / 向下 -2 / 未知 0）~~ **已废除（2026-09-08）**：`current_trend` 是滞后慢变量，震荡市里一路喊 down、市场没跌（8/24~9/1 连续 down 但实际 +1.13%/+0.86%/+0.86%），方向命中率 <50% 负贡献。**引擎有效性复盘结论（见 `engine_effectiveness.py`）：缠论结构信号（趋势/方向）滞后，方向判断必须改用时效信号。**
- **买卖点因子（弱方向信号，2026-09-08 重构）**：方向分只取「近期 60F/15F 买卖点」弱权重 ±1（买点 + / 卖点 -），窗口 20 天内；**日线/周线买卖点不进方向分**。
  - ⚠️ **买卖点只当「点位锚」，不当「方向锚」**：买卖点精准命中极值 61.9%（±0.5% 内），是支撑/压力的第一来源；但它也是"已发生转折"的滞后结构信号，用它判方向会重蹈趋势因子覆辙。
- **confidence 降权**（2026-08-25 优化）：无背驰的一买/一卖（`confidence<0.6`，如日线一卖@3847.09 无背驰 confidence=0.5）是弱信号，方向打分权重**减半**（±2→±1、±1→±0.5）。回测：方向相反率 30.3%→28.2%、规避率 15.4%→19.7%（弱信号不再与背驰确认的强信号同权重，方向更保守、错误更少）
- **MACD 动能因子**（2026-08-25 新增，DRAGON BALL模型"日线死叉"启发，回测验证）：日线 MACD(12,26,9) 的 DIF 在 DEA 上方（多头区）→ +1；下方（空头区）→ -1。回测：多头区次日涨率 62% vs 空头区 50%（弱趋势确认因子，权重 ±1）；**注**：日线底背离样本太稀疏（190 日仅 2 次）无法统计验证，"下跌衰竭"靠「假破位」判定（见第六节）落地
- **时效信号因子（方向主判三因子共振，2026-09-08 新增，替代已废除的趋势因子）**：
  - **DRAGON BALL模型 定调**：DRAGON BALL模型 是强时效信号，能当天自我修正（如 9/7 午后"60F 极弱"→ 9/8 隔夜"极弱解除"）。方向以 DRAGON BALL模型 最新定调作**校准信号（±1，与 MACD/BOLL 同级）**，不作单一主判——避免重蹈「DRAGON BALL模型 硬猜方向打回 52.6%」覆辙（见第四节）。
  - **BOLL 变盘概率**：60F/日线变盘概率（涨% vs 跌%）偏离 50% 超过 15pct → ±1（如 60F 涨 28% = 偏空 +1）。
  - **MACD DIF 拐头**：DIF 拐头向上 +1 / 拐头向下 -1（动能边际变化，比绝对多空区更及时）。
- **总分**：≥2 → 偏多；≤-2 → 偏空；|总分|≤1 → 方向不明；其余 → 震荡（按 15F 信号微调偏多/偏空）
  - ⚠️ 阈值从「≥3/≤-3」下调为「≥2/≤-2」（2026-09-08）：废除趋势因子（原 ±4 大头）后总分尺度缩小，若不调阈值则「偏多/偏空」几乎触发不了、全落到震荡/方向不明。

### 2. 「方向不明」状态（方向相反率 -15.8pct 的主要来源）
- 触发条件：|总分| ≤ 1（多空平衡）**或** 15F BOLL 带宽 < 1%（极度收口变盘在即）
- 输出「方向不明」，**不硬猜方向**，给 A/B 双向剧本

### 3. 支撑/压力（2026-08-25 回测重定：前低优先）
- **支撑** = **前低（最近 10 日最低 low）**；前低被跌破 → BOLL 下轨兜底 → 再无则近期买点
  - ⚠️ **前低时点边界**（2026-08-25 纠正）：前低 = **截至「昨日收盘」的最近 10 个已收盘交易日最低，不含当日盘中未确认的低点**。否则会把"当日刚出的低点"误当成"预测的支撑"，造成"精准命中"的假象（实为循环论证）
- **压力** = 上方最近的 **55 线**（高于现价的最低值）；55 线缺失 → 近期卖点 → BOLL 上轨
- 各带 **±0.5% 容差**，标注为区间带（如「支撑 3851±19」）而非精确单点
- ⚠️ 2026-08-25 对照回测（「支撑跌破 6 次」根因）：55 线做支撑太贴价（离现价 1.18%），趋势稍强就跌破，支撑守住率仅 **57.4%**；改用「前低」守住率 **91.5%**（+34pct）、区间覆盖 79.2%→81.0%；BOLL 下轨 84.6% 次之。**结论：55 线只用于「压力」，不再用于「支撑」**

### 4. 方向与关键位分离（重要原则）
- **方向**：用时效信号（DRAGON BALL模型 + BOLL 变盘概率 + MACD 拐头）+ 近期 60F/15F 买卖点弱权重
- **关键位**：**支撑用前低 + BOLL 下轨 + 买卖点**；**压力用 55 线 + 买卖点 + BOLL 上轨**

### 5. 逆势反抽纪律（2026-08-25 级别间背离回测）
- **日线空头区（MACD DIF<DEA）里，60F 反抽站上 MA55 = 反抽遇阻信号，不是买点**。回测：空头区+60F站上MA55 3日后 -0.43%（上涨 36%），而多头区+60F站上MA55 +0.23%（59%）。同向才强，逆向是反抽。
- **操作提示**：空头区反弹到 60F55/压力位附近 → 逢高减仓、不追涨；只有「有效站稳 + 日线 DIF 重新拐头向上（拒绝死叉）」才考虑翻多。

## 三、MA55（55 线）回测关键发现

### DRAGON BALL模型 的 55 线「准」在关键位，不在方向

| 维度 | 用法 | 结果 | 结论 |
|---|---|---|---|
| 方向信号 | 站上/跌破 55 线判断多空 | 相反率 36.5% | ❌ 不如买卖点 29.8% |
| **关键位** | 55 线作为支撑/压力 | **区间覆盖 79.6%** | ✅ 远优于买卖点 38.6% |

- 60F 版区间（188 样本）：55 线框住次日走势成功率 **79.6%** vs 买卖点 **38.6%**（差一倍多）
- 这解释了 DRAGON BALL模型 整体方向准确率（47.4%）高于引擎（31.6%）——**关键位准带动了整体胜率**

### 结论
**MA55 是「关键位」工具，不是「方向」工具**。所以 v5 把它接在「支撑/压力」维度，方向判断原样不动。

## 四、关键反直觉发现 ⚠️

**DRAGON BALL模型 方向校准「适得其反」**：
- DRAGON BALL模型 整体方向准确率 47.4% > 引擎 31.6%，看似该用来校准
- 但「方向不明时用 DRAGON BALL模型 硬猜方向」把相反率从 36.8% 打回 52.6%（v3 回测验证）
- **正确用法**：方向不明就保持「方向不明」（规避），DRAGON BALL模型 仅作**参考标注**、不替代判断

## 五、仍未解决（诚实说明）

1. 方向相反率仍约 28~30%——缠论买卖点是"已发生转折"的结构类信号，趋势反转初期天然滞后，靠"变盘信号前置预警"（带宽收口、日线零轴金叉/死叉）逐步改善。
2. 区间带 ±0.5% 为经验值。
3. 15F 信号在方向判断里可能是"噪音"（日线版相反率 29.8% 低于 15F 版 36.8%），方向判断或以大级别为主更优——待进一步确认。
4. **剧本名义概率的分配机制**（2026-09-17 登记，详见第八节 **OBS-2**）：9/14–9/16 连续三期实际主导剧本**不高于**当期名义最高概率（其中 2 期非最高、1 期并列最高），怀疑概率分配过度依赖长端（日线 / 120F）与机械分，而低估短端转向与量能变化。累计 ≥5 期或能指认结构性原因后，提请**专项审视**（审视分配方法本身，而非简单调权重）。

## 六、偏差归因与统计（复盘时执行）

每次复盘上期预判时，按以下 5 条记录偏差：

1. **偏差归因**：预判与实际差在哪（方向/区间/支撑/压力哪项错了、差多少）
2. **可预料性**：该偏差是否可预料（可预料-技术信号固有局限 / 不可预料-消息面突发 / 部分可预料）+ 一句原因
3. **偏差标签**：给偏差打分类标签（如"压力位短暂突破""支撑精准但未触及""方向正确区间偏移""消息面突发打乱技术结构""三买信号延迟确认"）
   - ⚠️ 2026-08-25 新增「真破位/假破位」判定（落地 DRAGON BALL模型"下跌衰竭"启发）：**「支撑跌破」必须先区分真/假破位**——收盘价 < 支撑 = 真破位（记「支撑跌破」）；盘中破但收盘收回支撑上方 = 假破位（记「下跌衰竭/假破位」，指向相反结论，绝不混入「支撑跌破」计数）
   - ⚠️ 2026-08-25 标签三分类（避免正面/中性标签虚增「规律已现」）：
     - **真偏差类**（计入 ≥3 阈值）：方向错误 / 方向部分 / 支撑跌破 / 区间下沿破位 / 区间向下偏移 / 压力位未触及 / 压力位短暂突破 / 反弹遇阻力位未破
     - **正面类**（不计入，是模型有效的证据）：支撑精准命中 / 压力精准命中
     - **中性类**（不计入，无新数据）：延续性参考
4. **统计积累（四维配对计数，2026-08-26 起，替代单纯偏差标签计数）**：
   - 读 forecast_chain.json 所有已复盘记录，对 **4 个维度分别做「✅命中 / ⚠️部分 / ❌失效」配对计数，分别计数、绝不抵消**（禁止「命中+1 失效-1」这类会抵消的记法，否则看不到结构）：
     - **方向**：✅命中 / ⚠️部分 / ❌相反
     - **区间**：✅命中 / ⚠️偏移 / ❌破位
     - **支撑**：✅守住 / ⚠️部分 / ❌跌破
     - **压力**：✅守住 / ⚠️部分 / ❌突破
   - 判定来源：review 的 `direction_verdict / support_verdict / resistance_verdict / range_verdict` 字段（或 direction/support/resistance/range 文本的 ✅/⚠️/❌ 前缀）
   - 算「纯命中率」= 命中 / (命中+部分+失效)；「延续」类（周末无新行情、无实际验证）单独记录、不计入
   - **持续记录含已改动部分**：已修改的规则（如「支撑改前低」）必须继续追踪命中/失效，保留「改前 vs 改后」对比，便于未来证伪时回滚
   - 某维度「失效」类标签累计 ≥3 次 → 仅标注「规律已现」供观察，**绝不自动修改任何策略/逻辑/参数**（改一处可能引发新的连锁反应、形成奇怪循环，先继续观察积累样本）；偏差标签 bias_type 保留作为辅助分类（真偏差/正面/中性三分类）
   - ⚠️ 2026-08-31 起「支撑跌破」「压力位短暂突破」两个规律由用户拍板**实装**（累计 7 次 / 8 次，样本已够），实装为以下两条规则，观察两天效果，可回滚：
     - **压力位突破确认**（实装「压力位短暂突破」8 次）：压力位被突破后**不立即追多**，需满足「放量 + 收盘站稳压力位上方」才确认有效突破、看更高目标；否则视为「假突破」不追高，等回踩原压力位（转支撑）企稳再考虑。
     - **支撑位保守设定**（实装「支撑跌破」7 次）：支撑位优先用「大级别强支撑 + 多重共振」（周线一买 / 前低 / 60F 中枢下沿 至少两重），避免单一小级别贴价支撑；单一支撑来源时向下预留缓冲（支撑位 × 0.99 或下移一个关键位）。
   - ⚠️ **2026-09-17 新增出口**：若复盘发现的**不是某个维度记错，而是打分机制漏算了某类信息**（跨维度机制性问题），不要塞进 `bias_type` 了事 —— **登记到第八节 OBS 表**，按该节「三问」自检并在对应 OBS 下追加样本；样本达标后提请用户拍板，**不得自行实装**。
5. **写字段**：把 bias_type / foreseeable / foresee_reason 写进该记录 review 字段

#### OBS-1 · 「条件性双向 → 0 分」系统性低估可验证触发路径

- **首次登记**：2026-09-17（本链第 47 期复盘）
- **机制描述**：v5 的「DRAGON BALL模型 条件性双向 → 0 分」规则把「双向」一律当成「无信息」。但当双向的两个分支**触发条件清晰、当日即可判定触发与否**（如「跌破 3852 → 走反弹」「站上 3905 → 继续上行」），且两侧**空间不对称**时，「双向」本身携带的是**强信息** —— 它标出了当日唯一需要盯的**决策位**，而不是模糊。

**一、结构性归因（根因指认）**

5 期样本（9/14~9/18 morning）共同模式：

| 期 | v5 方向分 | 剧本 A 定义 | A 概率 | 实际主导 | 实际路径 |
|---|---|---|---|---|---|

| 9/15 | -3 偏空 | 反抽 15F55 失败阴跌 | 40% | B（40% 并列） | 窄幅磨底 |
| 9/16 | -3 偏空 | 反抽失败/破 3852 加速 | 40% | C（25% 最低） | 放量反抽突破 |
| 9/17 | -2 偏空 | 反抽 30F55 受压回落 | 40% | B（35% 次高） | 带内消化 |

**根因：剧本概率分配是「方向打分」的机械映射，不是独立的概率评估。** 三条证据链：

1. **概率与方向同源**：5 期方向全部「偏空」，剧本 A 就全部是「反抽受阻→续跌」的**偏空路径文字化**，概率也给得最高（45/40/40/40/36）。「方向判偏空」与「剧本 A 概率最高」是**同一个判断说了两遍**——A 概率基本是方向总分（-3/-3/-3/-2/-3）的单调函数，概率层没有引入方向层之外的任何新信息。
2. **短端转向与量能从未进入概率层**：9/16、9/18 两期晨报 direction 文本已显式写入「短端 15F/30F/60F 进入多头区、DIF 拐头向上」「放量站上关键位」「15F 带宽极度收口变盘在即」，但这些信号只进了**叙述**、没进**概率分配**——剧本 C（放量突破）仍只给 25%/30%，剧本 A（续跌）仍最高。方向层与概率层**共用一个偏空打分**，短端多头 + 放量 + 收口这些「向上/变盘」信号在两个层里都被压掉了。
3. **C 剧本是「被动剩余」**：5 期 C 概率（25/20/25/25/30）基本是 `100 − A − B` 的被动余数，B 是固定档，没有任何一个独立信号在给 B/C 加权。当实际走「放量突破」（9/16、9/18）时，主导剧本必然落在名义非最高的 C 上。

**二、与 OBS-1 / OBS-3 同源确认**

- **OBS-3**（量能极值/带宽收口未入权重）：「变盘概率信号」没有承接层。
- **OBS-2**（剧本概率被方向绑架）：概率层没有独立评估「突破/变盘」路径。

三者同一根源：**方向层（偏空）垄断了从「方向标签」到「剧本概率」的全部输出，短端转向、量能、收口这类「变盘/突破」信号没有一个独立层来承接。**

**三、改前 vs 改后 实装方案（供用户确认，不自行实装）**

核心：**把「剧本概率分配」与「方向打分」解耦**。方向分不动（仍只判方向标签）；概率层新增独立的「变盘倾向分」。

**改前**（现状）：
- 剧本 A = 延续方向路径，概率 ≈ 方向强度单调映射（方向越偏空，A 越高）

- 剧本 C = 反向/突破路径，概率 = 100 − A − B（被动剩余）
- 概率层无独立输入

**改后**（方案）：

1. **短端背离**：15F/30F/60F 中 ≥2 个进多头区（DIF 向上）且长端偏空 → +1
2. **量能前兆**：缩量至近期极值（**5 日新低**，含当日）或放量站上关键位 → +1
