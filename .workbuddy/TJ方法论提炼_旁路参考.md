## 一、T&J 方法论完整框架（2026-09-02 深度提炼 v2）

> v1（08-31）只提炼了 5 点粗框架。v2 通读 08-14 ~ 09-01 全部原文后，补全为 12 个模块。
> 一句话概括 T&J 的体系：**「多级别 55 线锚定 + 双级差交叉验证 + 结构/X段分类 + 极强极弱状态机」**，用「明确标准」替代「凭感觉」。

### 1. 多级别 55 线体系（锚定系统，最核心）

- 完整级别序列：`3F / 5F / 15F / 30F / 60F / 120F / 日线 / 双日 / 周线 / 双周 / 月线 / 双月`
- **每一条 55 线 = 该级别的「多空分水岭」**。判断「回踩到哪」= 判断「回踩到哪一条 55 线」。
- 关键位不是孤立的点，而是「某级别 55 线」这个有明确技术含义的位置。

### 2. 中轨 vs 55 线：预警线 vs 分水岭（层次递进）

- **中轨（BOLL 中轨 ≈ 20 均线）比 55 线更灵敏，是「预警线」**。
- 「刺破中轨」= 预警信号；「有效跌破中轨」= 结构确认，进入下一级别。
- 「站上/跌破 55 线」= 该级别趋势分水岭的确认。
- 层次：**中轨（灵敏预警）→ 55 线（趋势分水岭）→ 更大级别 55 线（趋势确认）**。

### 3. 双级差体系（两个独立级别体系交叉验证）

- **体系 A（标准缠论级别）**：3F → 15F → 60F → 日线 → 周线 → 月线
- **体系 B（2.5 倍级差）**：5F → 30F → 120F → 双日线 → 双周线 → 双月线
- 交叉验证示例（08-17 原文）：「30F X段回踩 120F 中轨」= 体系 B 的「双日级别主涨段」，同时 120F 中轨支撑意味着「双日级别也是主涨段」。
- **两个体系同向共振时，上涨/下跌力量最强**；这是 T&J 比单级别体系多出的关键信息。

### 4. 结构 vs X 段（回调性质分类）

- **带结构回踩**（有笔/分型结构）→ 有持续性、回调深。
- **X 段**（无结构快速回调）→ 回调结束快、折腾短。
- 判断「刺破是 X 段还是带结构」是预判转折点的关键（09-01：「尾盘刺破 15F 中轨是带结构刺破，3 分钟 X 段可能性低」）。

### 5. 极强 / 极弱状态机（加速/降速信号）

- 每个级别有「极强 / 极弱」状态，状态变化是转折前兆：
  - **进入极强** = 加速上涨，锚定更小级别 55 线（如 60F 极强锚定 3F55）。
  - **解除极弱** = 降速，反弹信号。
  - **解除极强** = 减速，见顶预警。
- 08-27 原文：「60F 进入极强，锚定 3F55 线，极强顺利就还能涨一涨到明天」。

### 6. 压力区间的「唯一解」逻辑

- 关键压力常是**重叠区**（如 55 日线 - 233 日线 - 4012 重叠）。
- 突破重叠压力，必须「大级别主涨段叠加」（周线金叉下的 60F 主涨段 / 日线第三段上涨 / 周线级别上涨）。
- 09-01 原文：「233 日 - 4012 一带，**有且只有强势的日线主涨段，至少是 60F 主涨段才能突破**」——否则就是诱多。

### 7. 右侧标准（60F55 线）

- 反弹的「右侧确认标准」= **60F55 线**。
- 突破 60F55 = 解除周线极弱 = 反弹确认；不突破 = 反弹不成立。
- 08-17 原文：「为什么选了 60F55 作为反弹右侧标准，以及它如何操作」——核心思想是**有个明确标准 > 凭感觉/听风就是雨**。

### 8. 背离 = 买点（越跌越接近底部）

- 新低 + 底背离 = 更大级别买点（越跌越接近底部）。
- 顶背离 = 日线拐点。
- 08-18 原文：「跌破 60F55 则证明 60F 顶背离出现日线拐点，去更深的地方构建买点」。

### 9. 时间窗口

- 月线死叉窗口（9 月第一周后解除）、9.3-9.4 低点窗口。
- 用「时间周期」叠加「价格结构」双重定位拐点。

### 10. 市场结构与风格

- **beta 判断**：「任何方向都不存在很强的 beta，科技上涨不是 beta 推着全板块涨」→ 行情是结构性的，非普涨普跌。
- **alpha 判断**：个股抱团，「看的是市值 + 边际」，对边际变化和抱团敏感。
- **动量 vs 反转效应**：「市场动量衰退、反转效应为主」→ 酝酿回调或大级别风格切换；反转效应行业容量暂不支持持续走强。
- **风格周期**：「一个风格很难持续一个季度以上」；投机风格（中小盘）第三个月是加速期，但持续越久动量越强，反转越凶残；风格切换节点可能是突然出现趋势抱团方向，也可能是先泥沙俱下。

### 11. 宏观锚定

- **美元美债资金 = 海外定价权**：「如果不加息大概率持续逼宫」；9 月 FOMC 维持不变且指引混乱 → 大概率偏弱。
- **科技估值两段杀**：「7 月杀天花板（基本面），后面杀宏观压制估值」；进一步出清 → 风格切换时赔率更大。
- **ROI 的 R 锚定**：过去 tokens → 今年 ARR → 未来市场重新思考；「R 挂了行业没空间，R 有提升空间则底部已出」。

### 12. 操作心法（最难规则化，但最值得内化）

- **标准 > 感觉**：「有个标准肯定比凭感觉或听风就是雨好」。
- **尊重走势 > YY**：「一边心虚一边做多，尊重市场而不是 YY 那个 C 浪一定会新低给你好买点」。
- **右侧参与**：「反弹拐点你要先去参与，才有资格讨论后面会不会新低」。
- **不二极管**：「这里不用特别二极管了」——多空都可以，看结构演化，不预设立场。

## 五、量化回测结论（2026-09-02 新增）

> 把「中轨层次 / 极强极弱状态机 / 右侧标准(60F55) / 55线共振 / 刺破中轨」5 个可内化模块，
> 量化成纯价格 + 均线信号，用上证综指日线（405 根，2025-01-02~2026-09-02）+ 60F 数据回测。
> 口径与 v5 一致：T 日收盘出信号 → 预测 T+1 日。脚本 `.workbuddy/backtest_tj_v2.py` + `backtest_tj_v2_verify.py`。

### 三条核心结论

1. **方向维度整体无增量**：5 个模块量化后，绝大多数分档「涨/跌」概率落在 50%±10% 内，**没有一个能独立构成超越 v5 的方向因子**（组合因子命中 50.5% / 相反 32.7% / 规避 16.8%，相反率与 v5 的 28~30% 相当但命中率更低）。这再次印证 v5 既有结论——**T&J 是「关键位」工具，不是「方向」工具**。

2. **「持续极强」是唯一有看空优势的分档**（32.8%涨 vs 46.6%跌）：连续加速上涨后，次日易短线回落。但交叉验证发现它是**「1 日级别」的动量衰竭，非趋势反转**——3 日均值仅 -0.087%、3 日又涨回 55.2%。这对应 T&J 模块 5「解除极强 = 见顶预警」，且能**提前一天**（在「持续极强」阶段就预警），但只作用于短线，不能当趋势翻空信号。

3. **超跌反弹逻辑被验证**：破55线(60%涨)、空头排列(54%涨)、持续极弱(55%涨)、解除极弱(+0.30%)均偏涨——印证 T&J 模块 8「越跌越接近买点」+ 模块 5「解除极弱 = 反弹信号」。A 股 55 线下方是超跌区，反转效应强。

### 落地方式（不改主规则）

- 「持续极强」→ 作为 v5 偏空判断的**辅助确认信号**（当日线在 55 线上方连续加速 2 日以上，次日短线不追高、警惕回踩中轨）。
- 「解除极弱」→ 作为超跌反弹的**辅助确认**。
- 两者均**只作旁路标注，不进入 v5 方向打分**，待实盘样本累积（目标 ≥10 条）后再评估是否纳入。
