## 一、T&J 方法论核心框架（提炼）

### 1. 多级别 55 线锚定
- 3F55 / 15F55 / 60F55 / 55 日线，每一条 55 线是一个级别的「多空分水岭」。
- 判断「回踩到哪」= 判断「回踩到哪一条 55 线」。

### 2. 回踩级别递进（核心决策树）
- 冲高回落（未破 55 日线）→ 至少回踩 **15F55**。
- 15F55 支撑 → **日线极强延续**（回踩结束，看涨）。
- 跌破 15F55 → **升级 60F 级别**（看 60F55 + 日线中轨）。
- 跌破 60F55 → **日线级别调整**（看新低，但新低背离 = 更大级别买点）。
- 一句话：**「破一级、升级一级」**。

### 3. 结构 vs X 段
- 带结构回踩（3F 笔结构）→ 有持续性的回踩。
- X 段（无结构快速回调）→ 回调结束快、折腾短。

### 4. 背离 = 买点
- 新低 + 背离 = 更大级别买点（越跌越接近底部）。

### 5. 级别定性风险（经验，难规则化）
- 「底部已出」「不是 7 月那种风险」「9.4 时间窗口」——用级别比较来定性风险大小。
