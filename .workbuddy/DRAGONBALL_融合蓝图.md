# DRAGONBALL 融合蓝图（逻辑强化版）

> **定位**：把 5 篇方法论从「知识整理」升级为「可落地的规则规格」——每个融合点给出
> **原文判据 → 现有数据/脚本 → 缺口 → 融合动作 → 分级 → 验证方式**。
> **铁律（沿用既往）**：融合**不改引擎参数**，只加逻辑层；**先回测再进打分**；
> DRAGONBALL 是「关键位」工具，不是「方向」工具。
>
> 依赖：`DRAGONBALL_方法论.md`（术语 + 原文定义 + 三条链条 + 数学细节）

## 一、融合总原则（6 条，基于既往教训与回测）

| # | 原则 | 出处/依据 |
|---|------|----------|
| 1 | **先回测、再进打分**：任何新因子先量化回测，验证有预测增量才接进方向/置信度打分 | 旁路文档 §五：5 个可内化模块回测后「方向维度整体无增量」 |
| 2 | **DRAGONBALL 是「关键位」工具，不是「方向」工具**：落点是「跌到哪条线、破了意味着什么」 | 同上回测结论 |
| 3 | **不混语义**：MACD「稳定性」（篇4）≠ MACD「动能/背离」（现用），必须用**独立字段**承载 | §42.5；项目铁律「出参给人看、返回值给机器用」 |
| 4 | **纯函数加法优先**：P0 只做「现有数据直接算得出来的分类器/网格」，**不碰任何打分**，配单元测试 | 融合风险最小化 |
| 5 | **反向验证成对**：放宽/新增任何规则，都要配一条「证明它真生效」的测试（沿用 §30/§41 方法论） | 项目铁律 |
| 6 | **引擎参数不动，逻辑层扩展客观因素**：DRAGONBALL 融合属于「逻辑层」，不改 MA/MACD 参数 | 用户既定原则 |

## 三、P0 详细规格（可直接实现的判据 + 边界处理）

> 这一节是「逻辑强化」的核心：把原文的自然语言判据，收敛成**无歧义、可编码**的规格。
> 每个融合点都标注：输入字段、输出字段、精确判据、边界处理。

### P0-1/2：`classify_macd_state(dif, dea) → state`

篇4 六态判据（原文精确转写）：

| 状态 | 精确判据（原文） |
|------|-----------------|
| **极强** | `DIF ≥ 0` 且 `DEA ≤ 0` 且 `MACD > 0` |
| 强 | `DIF > DEA > 0` 且 `MACD > 0` |
| 中性偏强 | `0 > DIF > DEA` 且 `MACD > 0` |
| 中性偏弱 | `0 < DIF < DEA` 且 `MACD < 0` |
| 弱 | `DIF < DEA < 0` 且 `MACD < 0` |
| **极弱** | `DIF ≤ 0` 且 `DEA ≥ 0` 且 `MACD < 0` |

**逻辑强化点（原文没写、实现必须补的边界）**：

1. **`MACD > 0` ⟺ `DIF > DEA`**（标准 MACD 柱符号由 DIF-DEA 决定）。实现时**统一以 `DIF` vs `DEA` 比较为准**，
   避免与 `calc_tech.py` 里 macd 柱的 `(DIF-DEA)*2` 倍率定义冲突。
2. **六态完备性**：上述六态恰好覆盖「`DIF>DEA`（多头）× {跨零轴 / 均在0上 / 均在0下}」和
   「`DIF<DEA`（空头）× {跨零轴 / 均在0上 / 均在0下}」——无遗漏。
3. **边界（金叉/死叉点 `DIF==DEA`）**：此时 MACD 柱为 0，不属于任何六态。
   处理：返回 `'cross'`，并在报告中标注「当日金叉/死叉，看次日确认」。
4. **边界（`DIF==0` 或 `DEA==0`）**：原文极强/极弱用了 `≥/≤`，会同时命中。处理：
   优先按 `DIF>DEA`（多头）归极强、`DIF<DEA`（空头）归极弱；若 `DIF==DEA==0` 归 `'cross'`。

**输出**：`state ∈ {极强, 强, 中性偏强, 中性偏弱, 弱, 极弱, cross}`，附带 `zero_cross ∈ {golden, dead, none}`
（零轴金叉=极强等价、零轴死叉=极弱等价的第二识别）。

**接入点**：`calc_tech.py` 的 `report()` 已有 `dif/dea/macd/zone`，加一个 `macd_state` 字段即可。

### P0-3：`build_ma55_grid(levels) → {level: ma55}`

- 输入：多级别收盘序列（`calc_tech_multi.py` 的 `build()` 已产出多级别 `o/h/l/c`）。
- 输出：`{'15F': v, '60F': v, '日线': v, '周线': v, ...}` 每个级别的 MA55。
- 逻辑强化点：**55 线网格要作为「一等公民」独立输出**，而非散在各处；预判链的「关键位」字段
  从「上方最近一条 55 线」升级为「各级别 55 线网格 + 现价相对每条的位置」。
- 覆盖缺口：现有 v5 只在「压力维度」用了「上方最近 55 线」，未成网格。

### P0-4：`classify_break(close, prev_close, ma20, ma55) → break_state`

- 语义分层（篇4/5 综合）：
  - **刺破**（预警）：`low < 中轨 < close`（盘中跌破、收盘收回）→ 不构成级别确认；
  - **有效跌破**（确认）：`close < 中轨`（收盘价在中轨下方）→ 进入「主涨特征解除」候选；
  - **有效跌破 55 线**（趋势分水岭）：`close < ma55`。
- 逻辑强化点：原文「有效跌破」的判据是**收盘价**是否站回，不是盘中最低价；这是纠偏「跌破即转空」
  的关键——**单次收盘跌破中轨只是「解除候选」，不等于转空**（见 P1-9 的二次跌破）。
- 输出：`break_state ∈ {站上, 刺破收回, 有效破中轨, 有效破55线}`。

### P0-5：极强传递性（基于 P0-3 网格推导，无新函数）

- 规则：当某级别处于**极强**（P0-1）且 `close > 本级 MA55` 时，输出「有向上一级 55 线运动的惯性」，
  下一目标位 = 上一级别 MA55。
- 逻辑强化点：这是「多级别 55 线网格 + 极强状态」的**组合推导**，不需要新数据，是 P0-1×P0-3 的产物。

### P0-6：`classify_pullback(bi_list) → {x_duan, dai_jiegou}`

- 判据（篇3 精确转写）：
  - 「带结构」三要素：**顶分型 + 底分型 + 合并后至少 1 根 K 线**；
  - **X 段**：`N+2` 主涨段期间对 `N+1` 中轨回踩，而 **`N+1` 级别画不出一段结构** → 向下分解到 `N` 级别即 X 段。
- 逻辑强化点：X 段的核心判据是**「上一级别没结构」**，不是「本级别有没有结构」——
  这是原文反复强调、最容易被实现搞反的一点。实现时先判 `N+1` 级别是否有结构（用 `analyze_000001_multi.py`
  现成的分型/笔），再决定 `N` 级别是 X 段还是带结构回踩。
- 接入点：`analyze_000001_multi.py` 已有 `bi_count`（笔数）、`zhongshu_count`（中枢数）、分型，可复用。
- 输出：`{type: 'X段'|'带结构回踩', level: N, confirm_ma: 'N级别55线'}`。

## 四、P1 回测清单（先算、后决）

> P1 融合点**现有数据都能算**，但「有没有预测增量」必须回测证明，再决定进不进打分。

| # | 融合点 | 回测设计 | 判据阈值（先定，回测后调） | 通过标准 |
|---|--------|---------|--------------------------|---------|
| 7 | 持续极强看空 | 日线，T 日收盘出「持续极强≥2 日」→ 看 T+1 | 连续 2 日极强 | 次日跌率 > 次日涨率 且差值 >10pp |
| 8 | 主涨段判定 | 60F/日线，`N+2` 极强 + `N` 第三/五段 | 跨级别状态 + 段计数 | 判定为主涨段后 5 日新高概率显著 >50% |
| 9 | 解除两路径 | 日线，`close<中轨` 后跟踪「反抽再破」 | 二次收盘跌破中轨 | 「二次跌破后 5 日仍跌」概率显著 |

- 回测脚本模式沿用 `backtest_tj_v2.py`（口径一致：T 日收盘信号 → T+1 预测，涨 >0.1% / 跌 <-0.1%）。
- **结论纪律**：任一 P1 项若回测「无增量」，降级为**旁路标注**（不重演「塞进打分却发现没用」）。

### P1 回测结果（2026-09-24 实测，`backtest_dragonball_p1.py`，日线 405 根）

| 验证项 | 结果 | 结论 |
|---|---|---|
| 六态 → 次日方向 | 全部落在 50%±10% 内 | **无独立方向增量**（与旧口径一致：六态是「关键位」工具，非「方向」工具） |
| 持续极强（MACD 六态口径） | n=21，涨 52.4% vs 跌 28.6% | **偏多**（趋势延续），与旧「价格加速」口径（偏空）**方向相反** |
| 顶背离 | 非极强+顶背离 n=24 跌 62.5%；极强+顶背离 n=2 样本不足 | 顶背离在**非极强**下看空；「极强下背离失效」**暂无法证实**（样本不足） |

**核心发现（本轮最有价值）**：两种「极强」口径方向相反 ——
- 旧「价格加速」口径极强（`close>55 且偏离扩大`）= 短线超买 → 次日**偏跌**（动量衰竭）；
- 篇4「MACD 六态」口径极强（`DIF≥0 且 DEA≤0`）= 多头启动初段 → 次日**偏涨**（趋势延续）。

这**实证了蓝图原则 3「不混语义」**：若当初把两个口径混成一个「极强」字段，会得到自相矛盾、
毫无预测力的结果。二者必须并存、独立标注。

**落地决策**：
- **保留**现有「价格加速」口径的「持续极强/解除极弱」旁路信号（已回测验证看空/反弹）；
- **新增** `macd_state` 六态字段（已接入 calc_tech / forecast_analyze），**只作「稳定性」参考标注，
  不作方向信号**（样本 21 不足以强落地，记为观察，待更多样本）；
- 顶背离的「极强下失效」需更低级别/更多样本验证，**暂不落地**。
- **P1-8 主涨段判定已落地（2026-09-24 晚）**：`detect_main_up` 纯函数（触发 = 极强**或**零轴金叉
  + N 级别上涨 + N 级别低位），X段判定从「单级别 macd_state 极强/强近似」升级为「严格跨级别公式」。
  接入 `analyze_000001_multi.py`（`main_up` + `xduan` 输出）。
  ⚠️ 精度边界：① 本脚本四周期（日/120F/60F/15F）非篇4 标准 4 倍级差，「N+2 触发」降级为
  「上一级触发」（跨一级近似跨两级）；② 最顶层「日线主涨段」缺周线触发，用日线自身极强/金叉近似；
  ③ 「第三/五段」精确段计数需缠论**线段**划分，chan_signal 只输出笔，`up_segment` 作描述字段、
  不参与布尔判定。

### P1-8 / P1-9 回测结果（2026-09-24 晚补测，`backtest_dragonball_p1b.py`，日线 405 根，笔 29 条）

> 补上「已落地但增量未回测」的两个融合点：主涨段判定（`detect_main_up`）与解除两路径（`track_break`）。
> 精确复现：chan_signal 全量笔 + 逐日过滤「已完成笔」（`end_index ≤ T`），无未来函数。

| 验证项 | 结果 | 结论 |
|---|---|---|
| P1-8 主涨段 → 破前 20 日高点 | 主涨段 **52.2%** vs 基线 39.7%（**+12.5pp**，n=23） | **有增量**：主涨段预测「中期新高」 |
| P1-8 主涨段 → 破前 5 日高点 | 主涨段 56.5% vs 基线 60.6% | 无增量（短期新高无区分度） |
| P1-9 二次跌破 → 5 日仍跌 | 二次跌破 **45.8%** vs 解除 37.5% / 反抽突破 35.3% | 相对更偏空（+8.3pp），但绝对 <50% |

**P1-8 结论**：主涨段判定的增量在「**创 20 日新高**」而非「创 5 日新高」——主涨段是中期上涨结构，
预测的是中期新高。n=23 样本偏小，方向正确、幅度 +12.5pp。**作关键位/结构字段有信息量，仍不进方向打分。**

**P1-9 结论**：二次跌破确实比首次解除更偏空（45.8% vs 37.5%，相对 +8.3pp），但绝对概率 <50%
（5 日后 54% 反涨）——**实证篇5「解除 ≠ 下跌」：即便「二次跌破」这个最强解除信号，5 日内继续跌的
概率也不到一半**。故二次跌破只作「回调升级」标注，不当「转空」信号。

## 六、融合后怎么验证（反向验证设计，沿用 §41 方法论）

每落地一个融合点，必须成对交付：

1. **正向测试**：构造典型输入，断言输出状态正确（如 dif=1/dea=-0.5/macd>0 → 极强）。
2. **反向（变异）测试**：把判据改错（如极强条件 `DEA ≤ 0` 改成 `DEA < 0`），断言测试**必须变红**——
   证明测试真能抓住实现偏差，而不是「恒绿形同虚设」。
3. **语义隔离测试**：`macd_state`（稳定性）与现有 `dif_dir`/MACD 动能字段**必须独立**，断言二者不会互相覆盖。
