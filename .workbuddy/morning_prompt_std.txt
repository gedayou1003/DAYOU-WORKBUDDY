> 执行本块前先读 `.workbuddy/预判规则_v5.md`（v5 规则 + 偏差归因统计的唯一权威文件）。
1. **读预判链**：读 `.workbuddy/forecast_chain.json`（不存在则跳过复盘直接写本期预判）。
2. **复盘上期**：找最后一条 `status="pending"` 记录，运行 `$PY .workbuddy/get_daily_ohlc.py` 取实际 OHLC，对比"方向/区间/支撑/压力 vs 实际走势"，逐项判定 ✅命中/⚠️部分/❌相反。将该记录 status 改 `verified` 并写 review 字段。
   - 晨报→验证前一日 16:00 的"次日预判"（今日开盘初验）。
3. **形成本期预判**：按 `.workbuddy/预判规则_v5.md` 第二节 v5 规则，给出"今日全天"预判（方向/区间/支撑/压力/置信度/依据），追加新记录到 forecast_chain.json（status="pending"）。
4. **报告章节**：晨报末尾新增 `## 技术预判与复盘`（上期复盘表 + 本期预判）。
5. **预判输出规范**：
   - 关键位英文缩写：Resist / Supp / Bull / Bear / Side / Day H / Day L，相对现价标注百分比（如 +0.05% / -0.65%）
   - 用 show_widget 输出 SVG 预判走势图（viewBox="0 0 680 470"）为「条件触发决策路径图」：主路径（现价→决策位）+ 决策点（菱形）+ 分支（放量突破=红 / 缩量假突破·诱多=绿），每条分支标注触发条件 + 目标位；决策位/触发条件来自引擎C路径推演 + v5关键位（前低/55线），红涨绿跌
   - **y 轴铁律**：价格越高 y 越小（上=高价下=低价），映射公式 `y = 底部 - (价格-最低价)/价差*图高`，绝不能 y=价格*比例（会上下颠倒）
6. **偏差归因与统计**：按 `.workbuddy/预判规则_v5.md` 第六节执行。

## 第五块：行业强弱榜（申万一级实时 + 星球/缠论/复盘三要素推导）

> 目标：输出「行业强弱榜」——不只看涨跌幅，而是按 v5 预判模型一致的推导逻辑，结合「星球观点 + 缠论信号 + 观察统计复盘经验」三要素，给出上榜行业的方向/强度/置信度/依据。

### 数据层（跑两个脚本）
1. 实时涨跌幅：`$PY .workbuddy/scan_sw_realtime.py`（东财妙想，30 个申万一级行业实时涨跌幅，时间戳到当前分钟）
   产物 `.workbuddy/backtest_data/scan_result_sw_realtime.json`（`ts`/`count`/`industries` 按涨跌幅降序，缺「综合」兜底分类属正常）
2. 缠论方向分：`$PY .workbuddy/scan_ths.py`（同花顺归组，T+1，方向为慢变量相对稳定）
   产物 `.workbuddy/backtest_data/scan_result_ths.json` 的 `sw_agg`（`name`/`direction`/`volatility`/`score`/`members`/`trend`）
   降级：akshare 报错则跳过缠论方向分，仅用实时涨跌幅 + 星球观点

### 推导层（与 v5 预判模型一致，三要素）
1. **星球观点**：从第一块星球内容提取被明确看好/看空的行业（如 AI 算力链→电子/通信/计算机、存储国产化→电子、防守→银行/公用事业/煤炭）
2. **缠论信号**：sw_agg 的 `direction`（趋势+买卖点+MACD 加权）；买卖点信号背书——三买/三卖 conf0.75=强信号、一买/一卖 conf0.5=弱信号、无信号=裸趋势
3. **复盘经验**（应用观察统计已积累的规律，见 v5 第六节）：
   - |direction|≤1 或缠论方向与星球观点背离 → 标「方向不明」，不硬猜
   - 关键位贴价（对应「支撑跌破/压力位短暂突破」规律）→ 置信度下调
   - 缠论方向与实时涨跌幅方向相反 → 提示「趋势反转期买卖点滞后」（对应「方向相反」规律），谨慎

### 输出层（晨报末尾新增 `## 行业强弱榜` 章节）
- **做多榜 TOP3**：方向明确偏多 + 星球共振 + 有买点背书（标注：行业/实时涨跌幅/缠论方向分/星球依据/置信度）
- **规避榜 TOP3**：方向明确偏空 + 有卖点背书（三卖/一卖）
- **共振/背离说明**：星球观点、缠论方向、实时涨跌幅三者一致=高置信度共振；两两矛盾=标「方向不明」或「背离待观察」
- 命中「规律已现」标签的行业（如方向相反、支撑跌破）单独标注提示
