# 报告逻辑·排版·完整性规范 v2

> 本文件是「作战报告」（晨报 / 午间 / 收盘三档）的组织、排版与完整性权威规范。
> 与 `.workbuddy/预判规则_v5.md`（预判逻辑）并列，二者共同约束报告质量。
> 适用范围：家里 / 公司两边手动触发报告生成，引用本文件核对。

---

## 一、报告定位（一句话）

一份报告回答三个问题：**发生了什么（信息）→ 怎么判断（观点+技术）→ 该怎么做（预判+行业配置）**。

五块不是并列清单，而是一条**递进推导链**，前一块是后一块的输入：

```
① 星球信息 ──▶ ② 信息判断 ──▶ ③ 技术分析 ──▶ ④ 预判 ──▶ ⑤ 行业强弱榜
  原始素材       共识/分歧        客观结构       结论+复盘      三要素落地
```

## 二、报告逻辑（五块推导链）

| 块 | 角色 | 输入 | 输出（必须项） |
|---|---|---|---|
| **① 星球信息** | 原始素材 | 10 星球 + IMA 库 | 核心主线速览（5 句）+ 分板块逐条（标题+时间+要点，含图片正文，每条 1-3 行） |
| **② 信息判断** | 观点加工 | ① 的素材 | 共同观点（≥2 球一致）+ 相反观点（方向标签互斥）+ 隐含共识 + 上期共识复盘表 |
| **③ 技术分析** | 客观结构 | 缠论引擎 | 引擎 B 买卖点对比表 + BOLL×缠论变盘表（原样）+ 级别联动解读 |
| **④ 预判** | 结论+闭环 | v5 规则 + ③ | 上期复盘 + 本期预判（方向/区间/支撑/压力/置信度/依据）+ **偏差观察统计表** + 走势图 |
| **⑤ 行业强弱榜** | 三要素落地 | ①星球 + ③缠论 + 复盘经验 | 做多榜 TOP3 + 规避榜 TOP3 + 共振/背离说明 |

**关键原则**：五块必须**全部完整**，禁止「只重技术、轻星球明细/观点对比」的偏科。第四块缺失「偏差观察统计表」= 不合格；第五块缺失「共振/背离说明」= 不合格。

**去重原则（信息原子唯一落地，2026-09-08 新增；2026-09-16 强化为硬约束）**：五块是**递进推导链**，不是并列清单。同一个「信息原子」（一条主线、一个关键位、一个反转信号）全篇**只完整落地一次**，下游块用**短引用/指针**，禁止逐层重抄：

| 信息原子 | 唯一落地点 | 下游怎么写 |
|---|---|---|
| 主线素材（AI 算力/粮食/9·16…） | ① 星球信息·核心主线 | ② 判断只写「结论 + 共振源数 + 定性」，用「见第一块·一·N」指针 |
| 相反观点（方向分歧 + 三步自检） | ② 信息判断·跨星球观点对比 | ③④ 只引用判定结论，不重复 A/B 双方论据 |
| T&J 隔夜定调原文 | ① 星球信息·二 | ④ 预判只写「见第一块·二」，不重铺原文 |
| 技术点位（60F 三卖@3911 等） | ③ 技术分析·引擎表 | ④ 预判字段里带一次，剧本/纪律不再重复解释 |
| v5 打分明细 | ④ 预判·v5 打分明细 | ② 判断里只说「v5 -5（明细见第四块）」 |
| 剧本概率（A/B/C） | ④ 预判·剧本表 | ② 判断只写「剧本见第四块」，不重复三行触发条件 |
| **关键位（支撑/压力全列举）** | **④ 预判·关键位相对现价表** | **「完整预判字段」的支撑/压力行只写主位 + 「详见关键位表」，不再逐位重列** |
| **Cookie 通道失效等事件说明** | **报告头警示行** | **附录 A 表格内以「401 失效」4 字带过，不再另起一段解释** |

核心：**① 存素材、② 存判断、③ 存结构、④ 存结论**，各层只产出自己的增量，其余全部指针化。这一条已写进「报告生成流程.md·执行约定」。

**去重的量化红线（2026-09-16 新增，机器可查）**：9/16 晨报实测「3852 双向决策位」复述 **22 处 / 13 个小节**、「15F55 3885.90」**20 处 / 13 小节**，报告 3 天从 21.5KB 膨胀到 61.5KB（2.9 倍）。现设硬性上限，由 `check_layout.py` 第 6 类检查自动拦截：

| 检查项 | 上限 | 说明 |
|---|---|---|
| 同一价格关键位出现次数 | **≤ 8** | 超过即 WARN 并列出行号，提示改为指针 |
| 结论短语（诱多 / 暴力阳线 / 双向决策位 / 极度收口 / 墨迹） | **≤ 8** | 结论只在唯一落地点完整表述 |
| 事件说明（401 / Cookie 通道 / zsxq_cookie） | **≤ 4** | 报告头一次 + 附录一次即可 |
| 字段表 ↔ 关键位表双写 | **禁止** | 检测到两者并存即 WARN |

阈值与词表定义在 `.workbuddy/layout_spec.py·DUP_RULES`，调整只改该文件。

## 三、排版规范

### 3.1 标题层级
```
#  报告标题（含日期 + 档位）
## 第 X 块 · 块名
### 节名（块内细分）
#### 章（相反观点分章列表式，一节一方向）
```

### 3.2 表格优先
复盘、打分、关键位、偏差统计、行业榜一律用表格，不用散段：
- 复盘表：`维度 | 预判 | 实际 | 判定（✅/⚠️/❌）`
- 打分表：`因子 | 周线 | 日线 | 60F | 15F | 5F | 总分`
- 关键位表：`类型 | 价格 | 相对现价% | 基础`
- 偏差统计表：`维度 | ✅命中 | ⚠️部分 | ❌失效 | 纯命中率`

### 3.3 术语缩写（统一）
- 关键位英文：`Resist / Supp / Bull / Bear / Side / Day H / Day L`，**长词缩写成 RESIST / SUPP 防文字重叠**（走势图内）
- K 线：`H / L / O / C`
- 剧本：`Scenario A / Scenario B`
- 缠论术语保持中文：笔 / 中枢 / 背驰 / 一二三买卖点

### 3.4 颜色语义（红涨绿跌，中国习惯）
- 做多 / 上涨 / 突破 / 压力 → 红
- 做空 / 下跌 / 跌破 / 支撑 → 绿
- 方向不明 / 震荡 → 灰 / 中性

### 3.5 匿名化（两附录强制）
- **正文**直接表达观点，**不标来源代号**（"有观点认为""多个星球一致"）
- **附录 A**：抓取通道信息（Skill 4 球 + Cookie 6 球 + Cookie 状态 + 窗口）
- **附录 B**：星球代号对照表（代号 → 星球名 → 通道 → 类型）

### 3.6 走势图（SVG 独立文件）
- 生成独立 `.svg` 到 `outputs/000001_forecast_YYYY-MM-DD.svg`
- `.md` 用 `![预判走势图](xxx.svg)` 引用，**禁止内嵌 svg 代码块**
- y 轴铁律：`y = 底部 - (价格-最低价)/价差 × 图高`（价格越高 y 越小，绝不 `y=价格*比例`）

### 3.7 T&J 原文
出现 "Truth and Justice" 话题 → 一字不差归档 `outputs/TRUTH_AND_JUSTICE_原始记录_YYYY-MM-DD.md` 并在报告标注。

### 3.8 篇幅与粒度控制（2026-09-16 新增）

> 背景：9/11 → 9/16 三天内报告从 21.5KB 膨胀到 61.5KB（2.9 倍），第一块「星球信息」占 31.3%。
> 诊断结论：**不是条数问题，是粒度问题** —— 9/11 窗口 83 条只写 1,546 字，9/16 窗口 44 条却写 9,372 字。

| 位置 | 上限 | 说明 |
|---|---|---|
| 核心主线速览（三行） | **每行 ≤ 90 字** | 只给「是什么 + 最关键的一个数字」，展开交第一块 |
| ① 星球信息·每条 | **≤ 120 字（1-3 行）** | 超 200 字的条目必须拆成「主条 + 子条」或只留结论；宏观细节交第二块 |
| ① 星球信息·整块 | **≤ 5,000 字** | 超过说明粒度失控 |
| ④ 一句话预判 | **≤ 150 字** | **只写纯结论**：方向 + 核心带 + 最关键的反转条件。严禁把三因子/剧本概率/纪律在这里复述一遍 |
| ④ 剧本触发条件 | **每剧本 ≤ 80 字** | 细节交纪律节，此处只给「触发 + 目标位」 |
| ④ 操作纪律 ↔ 开盘观察 | **合并为一节「纪律与观察」** | 两节原本重叠 3/4（3852 / 量能 / 诱多 各重复 2 次） |
| 整份晨报 | **≤ 35,000 字** | 超限先查第一块粒度与第四块重复 |

**「一句话预判」的正确写法（示例）**：
> 偏空，核心带 3852-3886；上沿 3885.90（15F55）不破则维持「反抽 → 下跌」，下沿 3852.03 破位方式决定是加速下杀还是反弹启动。三因子明细见 v5 明细表，剧本与纪律见后两节。

—— 结论 + 两个关键位 + 一个分叉判据，其余全部指针化。

## 七、程序化自检（生成后强制，2026-09-04 新增）

> 之前的教训：版面每天靠 LLM 现场发挥，反复出现「缺块 / 错位 / 附录 A·B 对调 / 偏差期数过时」。
> 现已把「人看的 checklist」升级为「机器可执行的体检器」，报告落盘后必跑。

```
$PY .workbuddy/check_layout.py outputs/作战报告_<档位>_YYYY-MM-DD.md
```

体检器（`check_layout.py` + `layout_spec.py`）自动核对五类问题：

| 检查 | 规则 | 级别 |
|------|------|------|
| 缺块 | required（五块推导链：核心速览/星球/判断/技术/预判/行业榜 + 偏差统计）缺失 | ERROR |
| 缺块 | optional（附录 A·B、产物清单）缺失 | WARN |
| 顺序错位 | 如「星球信息」排在「技术分析」后、偏差统计被挪到行业榜之后 | WARN |
| 附录语义 | A 必须=抓取通道、B 必须=星球代号，对调则提示 | WARN |
| 偏差期数 | 报告标注期数 ≠ forecast_chain.json verified 条数 | WARN |
| 块内子内容 | 信息判断须含「共同观点/相反观点」；预判须内嵌走势图 | ERROR |
| **排版重复** | **同一价格关键位 >8 次 / 结论短语 >8 次 / 事件说明 >4 次；字段表与关键位表双写** | **WARN（仅当日报告）** |

> 第 7 项（排版重复）2026-09-16 新增。原先 `check_layout.py` 只管「块在不在、顺序对不对」，
> 完全不查重复 → 规范与产出之间没有机器拦网，导致去重原则形同虚设（实测同一原子复述 22 次）。
> 阈值与词表在 `layout_spec.py·DUP_RULES`。**仅对当日报告执行**，历史报告是快照、不参与，
> 以保证「0 ERROR / 0 WARN」这道闸门对当日报告始终有效。

**关键版面条目（附录 A/B 语义、各档位 required/optional 块、偏差统计位置、去重阈值）如需调整，只改 `.workbuddy/layout_spec.py`，不改校验器本体。**
