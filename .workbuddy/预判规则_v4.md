## 一、背景：三处结构性硬伤

对最近 1 个月（19 个交易日）000001 走势做预判回测（无未来函数），发现原模型三处硬伤：

| # | 硬伤 | 症状 |
|---|---|---|
| 1 | 方向判断缺「方向不明」状态 + 无趋势因子 | 方向相反率 52.6% |
| 2 | 支撑/压力用「单点买卖点」且缺失无兜底 | 区间覆盖仅 10.5% |
| 3 | 买卖点信号无「变盘抑制」 | 信号滞后成反向指标 |

补救后（v4）净进步：

| 指标 | v1 原版 | v4 最优 | 改善 |
|---|---|---|---|
| 方向相反率 | 52.6% | 36.8% | -15.8pct |
| 方向命中率 | 31.6% | 36.8% | +5.2pct |
| 区间覆盖率 | 10.5% | 31.6% | 3 倍 |
| 支撑守住率 | 10.5% | 68.4% | 6.5 倍 |
| 压力守住率 | 36.8% | 47.4% | +10.6pct |

## 二、v4 预判规则（4 条）

### 1. 方向量化打分（替代主观拍脑袋）
- **趋势因子**：日线/周线 `current_trend`（向上 +2 / 向下 -2 / 未知 0）
- **买卖点因子**：各周期 20 天内近期信号加权——日线 ±2 / 周线 ±2 / 60F ±2 / 15F ±1（买点 + / 卖点 -）
- **总分**：≥3 → 偏多；≤-3 → 偏空；|总分|≤1 → 方向不明；其余 → 震荡（按 15F 信号微调偏多/偏空）

### 2. 「方向不明」状态（关键新增，方向相反率 -15.8pct 的主要来源）
- 触发条件：|总分| ≤ 1（多空平衡）**或** 15F BOLL 带宽 < 1%（极度收口变盘在即）
- 输出「方向不明」，**不硬猜方向**，给 A/B 双向剧本

### 3. 支撑/压力区间带（替代单点，区间覆盖 3 倍）
- 支撑 = 近期买点价位、压力 = 近期卖点价位，各带 **±0.5% 容差**
- 标注为区间带（如「支撑 3884±19」）而非精确单点

### 4. BOLL 上下轨兜底（无买卖点时）
- 无近期买点 → 用 15F BOLL 下轨当支撑
- 无近期卖点 → 用 15F BOLL 上轨当压力

## 三、关键反直觉发现 ⚠️

**T&J 方向校准「适得其反」**：
- T&J 整体方向准确率 47.4% > 引擎 31.6%，看似该用来校准
- 但「方向不明时用 T&J 硬猜方向」把相反率从 36.8% 打回 52.6%（v3 回测验证）
- **正确用法**：方向不明就保持「方向不明」（规避），T&J 仅作**参考标注**、不替代判断

## 四、仍未解决（诚实说明）

1. 方向相反率 36.8% 仍不低——缠论买卖点是"已发生转折"的结构类信号，趋势反转初期天然滞后，靠"变盘信号前置预警"（带宽收口、日线零轴金叉/死叉）逐步改善。
2. 区间带 ±0.5% 为经验值，可再放宽到 ±0.8% 复测。
3. 样本仅 19 个交易日（受 15F 分钟线数据深度限制，最多回放 1 个月）。
