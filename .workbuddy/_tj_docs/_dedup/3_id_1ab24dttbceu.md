# X段定义与应用

> 发布时间：2025-09-21

X段定义与应用

2025年09月21日 19:54

周五写了MACD稳定性与级差体系的基础知识，这篇讲一下X段的定义，毕竟之前经常提到这个概念，但也没给出过一个严格的定义，很多时候就靠自己理解。

首先要明白一个前提，X段是只有在主涨段或主跌段的情况下才会出现，本文依旧以主涨段举例，关于主跌段下的情况，可以自行做历史复盘，本文不再展开。

所谓X段，其区别的是带结构的一段，而带结构的一段，从缠论上讲，则必须有顶分型、底分型、合并后至少有一根K线三个要素。至于K线如何合并，这个就参考缠中说禅吧，非常的详细。

当N+2级别出现主涨段的时候，期间会有对N+1级别中轨的回踩。有时N+1级别回踩中轨的这个过程，在N+1级别，不足以画出一段结构，那么称N级别作为X段。这里N级别能不能画出结构不重要，它体现的是N+1级别没有结构，只要N+1级别没有结构，那么就称N+1级别向下分解后的N级别走势，为N级别的X段。

以上图为例，白色箭头就是这轮周线主涨段中的日线主涨段，中间的两段回踩，AB段明显是没有顶底分型的，或者强行算顶底分型后，中间合并不出至少一根K线。而CD段则是明显带有顶底分型，中间合并K线数量也够，足够画出一段结构。因此，在日线级别，AB段为不带结构回踩日线中轨，CD段为带结构回踩日线中轨；在60F级别，AB段就是X段，而CD段是三段下跌结构。

这里有的朋友可能会问，AB段能否作为日线的X段？这里就涉及到月线是否出现主涨段，由于级别太大，我们一般不讨论，但有时我们也可以这样做假设，即更高的级别也存在主涨段，毕竟周线中轨一直没破过。所以有时我们也会看到N+1级别的主涨段，出现N级别的X段，原因其实就在于假设N+2级别也有主涨段，是主涨段套娃的原因。这一段可能比较深奥，初学者不必深究。

拆解到60F级别来看，X段出现在明显的五段上涨之后。这里引申出三个条件：

1.X段必然出现在复合结构中，不能单独存在。如上图，60F的X段出现的复合结构是“五段上涨+X段+一段上涨”。正常的上涨结构，有三段、五段、双平台式，少数情况下存在一段。这里重点不在于60F除X段之外的结构走成什么样，而是在于60F的X段，成为了连接前后两个上涨结构的桥梁。

2.X段必然出现在某个上涨结构的最高点过后，起点一定是最高点而非次高点，否则就是别的结构。而X段的终点，则是回踩N+1级别中轨的结束点。即上述60F的X段，起点是五段上涨的最高点，终点是回踩日线中轨。

3.X段一个后验的条件，在于结束后必然突破N级别55均线，且新高前一个上涨结构高点（即X段起点）前，不再发生新低，否则变异为带结构的下跌段。如上图，X段结束后突破60F55线，且后续的新上涨结构新高了X段起点3636。

所以，综上所述，当出现N+2级别主涨段及N+1级别不带结构的回踩时，优先考虑N级别X段，以突破或不跌破N级别55均线为后端确认，一旦确认成功，则后续基本可以确定会新高。如果被N级别55均线压制且新低，则认为下跌发生升级，需另做考虑。

此外，就是X段不能孤立来看，由于级差体系有两套，有时可能相互穿插影响，需要具体问题具体分析，不能太形而上学。
