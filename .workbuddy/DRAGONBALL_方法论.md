### 1.2 状态机：极强 / 极弱（篇4 核心）

MACD 六种状态，判据**完全由 DIF / DEA / MACD 三者符号给出**：

| 状态 | 判据 |
|------|------|
| **极强** | `DIF ≥ 0`，`DEA ≤ 0`，`MACD > 0` |
| 强 | `DIF > DEA > 0`，`MACD > 0` |
| 中性偏强 | `0 > DIF > DEA`，`MACD > 0` |
| 中性偏弱 | `0 < DIF < DEA`，`MACD < 0` |
| 弱 | `DIF < DEA < 0`，`MACD < 0` |
| **极弱** | `DIF ≤ 0`，`DEA ≥ 0`，`MACD < 0` |

另六种金叉死叉形态：水下金叉 / 水下死叉 / 零轴金叉 / 零轴死叉 / 水上金叉 / 水上死叉。
→ **体系中「零轴金叉 ≡ 极强形态」「零轴死叉 ≡ 极弱形态」**（等价替代，是极强/极弱的第二种识别方式）。

> ⚠️ **本文最容易误读的一点**：原文专门澄清——
> 「这里 MACD 的强弱，**和行情的强弱没有关系**，它并不是字面意思，MACD 的强弱指的是**稳定性**。」
> 稳定性相对走势而言：**上涨行情中，强/极强形态 → 上涨更有持续性（做多胜率高）；下跌行情中，弱/极弱形态 → 下跌更有持续性（做空胜率高）**。
> 推论金句：「**极强形态不做空，极弱形态不做多**」。

**极强形态的三条稳定性特征**（原文以极强为例列举）：

1. **可能引发主涨段下的背离失效**——`N+2` 级别的极强引发 `N` 级别主涨段时，**`N` 级别以下的顶背离可能阶段性无效**（「背了又背」的根源是只看单一级别 MACD，不具显著性）。当极强度过、小级别主涨特征失效后，小级别顶背离才生效，**以跌破该级别 55 均线为标志**。在极强加持的主涨段下，**小级别顶背离很难跌破本级别 55 均线**。
2. **均线的大概率支撑位**——`N+2` 级别极强形态下，**首次回踩 `N` 级别 55 均线，极大概率得到支撑**，是「胜率极高的做多开仓点」。同时：若 `N+2` 极强形态下 `N` 级别**跌破** 55 均线 → **`N+2` 级别极强形态解除**，后续不再那么「稳定」。
3. **传递性**——极强形态**往往从低位上涨时出现**，因此可理解为「**低位突破本级别 55 均线的过程**」。传递性可衡量上涨持续性：指数**有效突破本级别 55 线后，有向更高级别 55 均线运动的惯性，直到被更高级别的 55 均线压制**。

### 1.3 结构判定：主涨段（篇5 核心）

**主涨段开始与结束的判定公式**（原文原话）：

> `N+2` 级别，MACD 进入**极强**状态，**或金叉**状态，那么 `N` 级别，将在**低位出现结构**后，出现**主涨段**。

- **「低位结构」**：一般是**第三段上涨，或第五段上涨**。多见情况是**第三段上涨前回踩 `N-1` 级别的 55 线**（因为 `N+2` 金叉往往传导至 `N+1` 极强，所以有回踩 `N-1` 55 线确认的可能性）。
- **极度强势情况下可以第一段就出主涨段，但概率偏小。**
- **主涨特征维持机制**：在 `N-1` 级别的波动中，**中轨往往会支撑，使得顶背离失效**。
- **主涨特征解除**：**直到有效跌破 `N-1` 级别的中轨**。

**解除后的两种演化**（关键：解除 ≠ 下跌）：

| 情形 | 后续路径 |
|------|---------|
| **①** | 跌破 `N-1` 中轨后**出现对 `N-1` 中轨的反抽，但被压制**；弱势情况下**甚至被 `N-2` 中轨压制** |
| **②** | 跌破 `N-1` 中轨后，**反抽突破中轨，甚至出现 `N-1` 级别 MACD 金叉**。后续**不管是否新高**，**二次跌破 `N-1` 中轨**（泛指**最后一次有效跌破**，因该过程可能发生多次）→ **至少回踩 `N-1` 级别 55 线，多数情况应刺穿 `N-1` 55 线，从而实现对 `N` 级别中轨的回踩** |

**闭环条件**：此时若 `N` 级别中轨支撑、**或 `N-1` 级别 55 线支撑（亦可视作 `N` 级别中轨支撑）** → 该回踩**视作 `N-1` 级别的 X 段** → 后续上涨结构**重新焕发 `N` 级别主涨特征** → 重复上述流程，**直到 `N` 级别中轨跌破，确认整个上涨结束**。

> **周线实例（原文翻译）**：季度级别 MACD 极强/金叉 → 周线级别在低位结构后出现主涨段（本例：从 2635 开始的**第五段**周线上涨）→ 第五段上涨前回踩 55 日线（因季线金叉传导至**月线极强**）→ 日线波动中**日线中轨支撑使日线顶背离失效** → 有效跌破**日线中轨**则主涨特征解除 → 二选一演化 → 最终「至少回踩 55 日线，甚至应刺穿，实现对**周线中轨**的回踩」→ 若在 55 日线与周线中轨之间任何位置止跌回升，**则这段回踩为日线 X 段**，后续仍将有周线主涨段。

### 1.4 结构判定：X 段（篇3 核心）

> 前提：**X 段只在「主涨段或主跌段」的情况下才会出现**（原文以主涨段举例；主跌段「自行历史复盘，本文不再展开」）。

**形式定义**（原文原话）：

> 「当 `N+2` 级别出现主涨段的时候，期间会有对 `N+1` 级别中轨的回踩。有时 `N+1` 级别回踩中轨的这个过程，**在 `N+1` 级别不足以画出一段结构**，那么称 `N` 级别作为 **X 段**。这里 `N` 级别能不能画出结构**不重要**，它体现的是 **`N+1` 级别没有结构**；只要 `N+1` 级别没有结构，那么就称 `N+1` 级别向**下分解**后的 `N` 级别走势，为 `N` 级别的 X 段。」

**「带结构」的严格判据**（缠论口径）：必须有**顶分型、底分型、合并后至少有一根 K 线**三个要素。

**原文例子**：某轮周线主涨段中的日线主涨段，中间两段回踩——
- `AB` 段：无顶底分型（或强行算后中间合并不出至少一根 K 线）→ 日线**不带结构回踩日线中轨**；在 60F 级别，**`AB` 段就是 X 段**。
- `CD` 段：有顶底分型、合并 K 线数量够 → 日线**带结构回踩日线中轨**；在 60F 级别，**`CD` 段是三段下跌结构**。

**X 段的三个条件**（原文列举）：

1. **必然出现在复合结构中，不能单独存在。** 例：「五段上涨 + X段 + 一段上涨」。正常上涨结构有**三段、五段、双平台式**，少数情况下存在**一段**。重点是 **X 段成为连接前后两个上涨结构的桥梁**。
2. **必然出现在某个上涨结构的最高点之后，起点一定是最高点而非次高点**（否则就是别的结构）；**终点 = 回踩 `N+1` 级别中轨的结束点**。
3. **后验条件**：结束后**必然突破 `N` 级别 55 均线**，且**新高前一个上涨结构高点（即 X 段起点）前，不再发生新低**；否则**变异为带结构的下跌段**。

**X 段的操作结论**（原文）：

> 当出现 `N+2` 级别主涨段 及 `N+1` 级别**不带结构**的回踩时，**优先考虑 `N` 级别 X 段**，**以突破或不跌破 `N` 级别 55 均线为后端确认**。一旦确认成功，**则后续基本可以确定会新高**。如果**被 `N` 级别 55 均线压制且新低**，则认为**下跌发生升级**，需另做考虑。

⚠️ **注意「X 段不能孤立来看」**：因级差体系有两套，可能相互穿插影响，需具体问题具体分析。〔也提到「主涨段套娃」——假设更高别也有主涨段时，会出现 `N+1` 主涨段里出现 `N` 级别 X 段；原文标注「初学者不必深究」〕

### 1.5 风格量化层（篇2/篇1）

| 术语 | 定义 |
|------|------|
| **核心命题** | 「**A股一切逻辑服务于筹码**」——基本面定价之外，**流动性和风险偏好**同等重要 |
| **有效收益率 `f(w)`** | 个股的「有效收益率」是**资金权重 `w` 的凸函数**。「资金集中时主线个股有更高边际收益，分散时边际收益递减」→ `f''(w) > 0` |
| **詹森不等式应用** | 凸函数：`E[f(X)] ≥ f(E[X])`。把**资金权重视为「概率分布」**，总收益率转化为「函数的期望」 |
| **结论 A** | **抱团（资金集中）→ 推高 A 股总市值**（因 `f` 严格凸增） |
| **结论 B** | **切换（资金分散）必然引发下跌**——「**必然不存在丝滑无伤的高低切换**」 |
| **三个贴合 A 股的假设** | ① **资金驱动型市场**：主线因资金流入产生流动性溢价，股价加速上涨（`f''(w) > 0`）<br>② **结构性行情主导**：A 股极少全面牛市，多数时间「主线涨、非主线跌」，分散必然纳入低/负收益个股，拉低总市值<br>③ **情绪放大效应**：资金集中时情绪放大主线涨幅（**凸性增强**）；分散时难成合力，总市值缺上涨动力 |
| **反身性（reflexivity）** | 「**主体认知（C）影响客体状态（S），客体状态变化反过来修正主体认知（C）**」的**闭环反馈**，最终导致系统**偏离「客观均衡」** |
| **系统脆弱性** | **≠ 不稳定性**。= 「**损失的敏感性**」+「**恢复的困难度**」= 「扰动响应 – 损失量化 – 恢复能力」 |
| **耦合关系** | 反身性往往是**系统脆弱性的放大器**：正反馈加剧扰动影响、延长恢复时间 → 提升脆弱性。数学上体现为「**反身性反馈强度 `k` 对脆弱性指标 `V` 的调制**」 |
| **盈亏同源** | 「市场总是自然而然地追求**高夏普率**的资产，对于持续上涨的追求**必然造成反身性**，反身性会进一步**强化夏普率**，而这一过程会**积累脆弱性**」——「投资界的信条是风险管理，即『找到风险最小、收益最确定的点，然后尽可能多的加杠杆』，但**杠杆的另一面则是系统脆弱性**」 |
| **周期轮回的根源** | 「尤其是在一个**做空机制不完善的市场**，这种**周期轮回将成为必然**」（不止 A 股；BTC、贵金属、某些「确定性最强」的权益资产同理） |
| **延迟反馈动力系统** | 用于分析「高夏普率资产资金涌入过多」的动态过程。闭环 `认知 → 资金 → 价格 → 波动 → 认知`，**每个环节存在天然延迟**（无法即时响应）→ **延迟导致反馈循环无法及时修正偏差** → 推动系统从「**稳健收敛**」走向「**脆弱发散**」 |

### 1.6 篇1/篇2 数学细节（公式图补全 · 2026-09-24 晚）

> 以下全部内容来自 26 张公式图的逐张读取（`_tj_imgs/p1_01~20`、`p2_01~06`）。符号保持原图记法。

#### A. 篇2：詹森不等式完整推导链（抱团推高、切换必跌的证明）

1. **詹森不等式（加权形式）**：`f` 为区间上的下凸函数，`x1..xn ∈ [a,b]`，权重 `a1+...+an=1` 且均为正 →
   `f(a1x1 + ... + anxn) ≤ a1f(x1) + ... + anf(xn)`，**当且仅当 x1=x2=...=xn 时等号成立**。
2. **核心变量定义**：
   - 资金配置权重 `wi`：市场 n 只个股，`Σwi = 1` 且 `wi ≥ 0`；
   - 个股有效收益率 `ri = f(wi)`，其中 `f:[0,1]→R` 是**严格凸函数且严格增函数**：
     `f''(w) > 0`（边际收益率递增——资金越集中额外收益率增长越快，贴合主线抱团/流动性溢价/情绪放大）；
     `f'(w) > 0`（权重越高个股收益率越高，贴合「资金去哪行情去哪」）；
   - 总市值收益率 `R = Σ wi·ri = Σ wi·f(wi)`。
3. **行情状态定义（A 股结构性行情的简化）**：
   - **分散行情**：`wi = 1/n`（n 极大，含大量非主线股，`f(wi)` 凸性弱甚至为负）；
   - **主线集中行情**：`w1 = ... = wk = 1/k`（k ≪ n，主线股有政策/业绩/资金驱动），其余 `wi ≈ 0`。
4. **权重的概率化**：权重满足分布条件 → 视为离散概率分布 `P(X=wi)=wi`，则 `R = E[f(X)]`。
5. **詹森直接应用**：`f(E[X]) ≤ E[f(X)] = R`，等号当且仅当 X 为常数（**均匀分散**）。
6. **权重期望的关键计算**：`E[X] = Σ wi²`：
   - 分散：`E[X] = n·(1/n)² = 1/n → 0`；
   - 集中：`E[X] = k·(1/k)² = 1/k`，**k ≪ n 故 1/k > 1/n**——集中度越高 E[X] 越大。
7. **结论**：
   - **集中行情总市值易涨**：`f` 严格增 且 `1/k > 1/n` → `f(1/k) > f(1/n)`，故 `R ≥ f(1/k)` 是**较高的下限**；且主线股 `f(w)` 凸性更强，实际值远高于分散情形；
   - **分散行情总市值易跌**：`R ≥ f(1/n)` 下限趋近 0 甚至为负（非主线股缺乏资金），分散必然纳入大量低/负收益个股拉低 R；
   - **不存在丝滑无伤的高低切换**——切换 = 权重从集中走向分散 = R 的下限从 `f(1/k)` 滑向 `f(1/n)`，数学上必跌。

#### B. 篇1：反身性与系统脆弱性的完整数学链

**B1. 反身性的数学表达**

- **静态（联立映射与不动点）**：`C = f(S)`（认知对客体的依赖），`S = g(C)`（客体对认知的响应）。
  不动点：`C* = f(g(C*))`，`S* = g(f(S*))`。线性化 `f(S)=a+bS`、`g(C)=c+dC` 时：`C* = (a+bc)/(1-bd)`。
- **反馈强度 `k = |b·d|`**（「认知→客体→认知」循环放大系数）：
  `k < 1` 负反馈主导，收敛到不动点（反身性弱，如成熟市场理性预期）；`k = 1` 中性；`k > 1` **正反馈主导，偏离不动点发散**（反身性强，如资产泡沫、恐慌性崩溃）。
- **股票市场线性示例**：`f(S(t-1)) = α + βS(t-1)`（前一日股价越高今日预期越乐观）、`g(C(t)) = γ + δC(t)`（今日预期越乐观今日股价越高）→
  `S(t) = (γ + δα) + δβ·S(t-1)`。
  **`δβ > 1` 股价指数发散（泡沫形成）；外部冲击使 β 变号、`δβ < -1` 股价断崖式下跌（崩溃）**。
- **动态（连续时间）**：`Ċ(t) = k1[f(S(t)) - C(t)]`，`Ṡ(t) = k2[g(C(t)) - S(t)]`（`k1,k2>0` 为调整速度；`f(S)-C` 是认知偏差、`g(C)-S` 是客体偏差，系统通过调整偏差实现动态反馈）。
- **延迟反馈映射**：现实中认知与响应有时间滞后 → `S(t) = g(f(S(t-τ)))`；离散模型 `C(t)=f(S(t-τ))`、`S(t)=g(C(t))`。

**B2. 系统脆弱性的数学表达（三维量化）**

- **冲击脆弱性**：`V = L(ΔS) / ||ε||`——单位扰动带来的损失。`ΔS = S(ε) - S*` 为偏离稳态程度；
  损失函数可取平方损失 `L(ΔS)=ΔS^T·ΔS`（连续变量）或 0-1 损失 `L(ΔS)=I(ΔS>θ)`（离散失效）；`||ε||` 为扰动范数（欧氏）。
- **尾部脆弱性（极值理论 EVT）**：超额损失服从广义帕累托分布（GPD）：
  `P(ΔS - u > x | ΔS > u) ≈ (1 + ξ·x/σ)^(-1/ξ)`，`x > 0`。
  `ξ` 为形状参数（尾指数）：`ξ > 0` 厚尾（幂律），**ξ 越小尾部越厚、极端损失概率越高、脆弱性越强**；`ξ = 0` 指数薄尾。
  **尾部脆弱性指标 `V_tail = 1/ξ`（ξ>0）**。
  金融实例：`VaR_α = inf{x | P(ΔS≤x) ≥ α}`；`CVaR_α = E[ΔS | ΔS > VaR_α]`；**脆弱性 `V = CVaR_α - VaR_α`**（差值越大「尾部厚度」越高）。
- **结构脆弱性（图论）**：系统为网络 `G=(V,E)`。节点脆弱性 **`vi = Bi/Di`**：
  `Bi` 介数中心性（枢纽作用，越高节点失效对网络影响越大）、`Di` 度中心性（连接数，越高越「稳健」）。
  物理意义：**枢纽作用强但连接少的节点（如单一核心银行）脆弱性极高**。系统整体 `V = Σ wi·vi`（wi 为节点权重，如资产占比）。
- **恢复能力**：`V = T_rec / ε_max`（恢复到稳态 95% 所需时间 ÷ 最大允许扰动强度）。
  指数恢复 `Ṡ(t) = -λ(S(t)-S*)` 时 `T_rec = ln20/λ`（λ>0 为恢复速率），`V = ln20/(λ·ε_max)`。
  脆弱性与「韧性（Resilience）」互补：韧性是恢复能力，脆弱性是韧性的反面。

**B3. 耦合：反身性放大脆弱性**

- 动态耦合模型：`Ṡ(t) = k2[g(f(S(t-τ))) - S(t)] + ε(t)`——外部扰动 ε(t) 触发响应，反身性通过反馈循环放大：
  `k = |b·d| > 1` 时扰动被放大，`ΔS(t)` 显著增加；
  **脆弱性指标 `V(k) = k · V0`（V0 为无反身性时的脆弱性）——正反馈强度 k 与脆弱性成正比**。
- 示例（银行挤兑）：客体 S=银行流动性、认知 C=储户恐慌程度；`C(t)=f(S(t-1))`、`S(t)=g(C(t))`；扰动=某银行违约传闻；正反馈 k>1 放大恐慌 → 流动性快速枯竭、`T_rec` 延长、`V` 急剧上升。

**B4. 高夏普率资产的完整四步（篇1 主体）**

1. **前提（初始吸引力）**：夏普率 `SR = (E[r]-rf)/σ`。「高夏普=安全高收益」形成市场共识 `C = f(S)`。
   初始阶段高夏普可能源于真实价值（技术壁垒/供需缺口），`C` 与 `S` 匹配，`k = |b·d| < 1`，系统收敛于均衡（资金小幅流入、价格平稳上涨），脆弱性较低。
2. **资金涌入（突破临界值）**：
   - 认知函数中 `b` 显著上升——「赚钱效应」使认知从「理性认可」变「非理性追捧」（`S(t-τ)` 哪怕小幅上涨也引发 `C` 大幅提升）；
   - 客体响应中 `d` 急剧上升——认知越乐观涌入资金规模越大（增量资金 `F(t) ∝ C(t)`），直接推高 `P(t)`、扩大 `Q(t)`；
   - **`k = |b·d|` 突破临界值 1，系统从「负反馈收敛」转向「正反馈发散」**：价格层面 `P(t) = γ + δβ·P(t-1)`（`δβ = k > 1`）泡沫式上涨；
     夏普率层面：短期上涨推高 `E[r]`、买盘支撑暂时压制 `σ` → 夏普率进一步走高（**虚假高夏普**），反过来强化「安全高收益」认知，闭环。
3. **三重脆弱性积累**：
   - **冲击脆弱性上升**：流动性「拥挤」（同质化买入渠道 ETF/量化策略）→ 有效流动性下降，反向扰动出现时卖出订单难找接盘方，`L(ΔS)=ΔP(t)²` 非线性增长；
     收益边际递减（新增资金预期收益低于早期）但认知未修正，小幅盈利不及预期 `||ε||` 就引发更大幅度下跌，V 翻倍；
   - **结构脆弱性恶化**：`Bi` 上升（高夏普资产成为市场「核心枢纽」，如某渠道资产占公募持仓 30%）、`Di` 下降（资金同质化、风险分散度下降、依赖单一逻辑如「低利率/政策支持」）→ `vi = Bi/Di` 大幅上升——一旦出问题风险快速传导全市场（原文举例：2021 年新能源渠道基金的流动性危机）；
   - **尾部脆弱性爆发**：初始「历史波动低」是薄尾（`ξ=0`）；资金涌入后交易拥挤使波动从正态转向**幂律厚尾**（`ξ>0` 且逐渐变小）——平时波动极小，极端情况（资金集中平仓）跌幅远超历史数据；`V_tail = 1/ξ` 上升，黑天鹅概率显著提升。**「看似稳健，实则脆弱」的核心数学逻辑。**
4. **脆弱性暴露（反身性反转）**：
   - 认知反转：`C(t)` 从「安全高收益」变「高风险低收益」，即 `f(S)` 斜率 `b` 由正转负（`b < 0`）；
   - 反馈强度反转：`k = |b·d|` 仍大于 1，但 `b<0`、`d>0` → `S(t)=g(f(S(t-τ)))` 指数下跌（`P(t)=γ+δβP(t-1)` 此时 `δβ < -1`，对应前述「崩溃模型」）；
   - 脆弱性量化爆发：冲击脆弱性 V 达峰值（单位扰动的价格跌幅是初始阶段数倍）；恢复能力下降（平仓成本高、流动性枯竭，`T_rec = ln20/λ` 大幅延长）；**杠杆加速崩溃**——高夏普资金常带杠杆（加杠杆不改变夏普率但放大收益），价格下跌触发强制平仓，形成「下跌→平仓→再下跌」负反馈，**让尾部损失进一步扩大（ξ 更小、`V_tail` 更高）——下跌比上涨更猛烈的原因**。

**B5. 延迟反馈动力系统（完整建模，篇1 压轴）**

- **变量表**：主体认知 = 预期夏普率 `C(t)`；客体状态 = 资产价格 `P(t)` 与实际波动 `σ(t)`；中介变量 = 资金流入规模 `F(t)`；关键参数 = 反馈强度 `k`（= 敏感度1 × 敏感度2 × 敏感度3）；延迟参数 `τ1, τ2, τ3`。
- **三大核心延迟**（现实中无法规避，导致反馈「滞后修正」）：
  `τ1` 认知延迟（投资者用历史真实夏普率形成预期，无法即时感知当前变化）；
  `τ2` 资金延迟（认知形成后募集资金、建仓需要时间）；`τ3` 波动延迟（资金涌入初期压制波动，拥挤的「副作用」需要时间显现）。
- **第一步（认知的延迟反馈）**：`Ċ(t) = α[SR(t-τ1) - C(t)] = α[(P(t-τ1)-rf)/σ(t-τ1) - C(t)]`，α>0 为认知调整速度——历史真实夏普率高于当前预期则上调预期，反之下调。
- **第二步（资金与价格的延迟互动）**：`F(t) = β·C(t)`（β>0 资金对认知敏感度）；`Ṗ(t) = γ[F(t-τ2) - δ·P(t)]`（γ>0 价格对资金敏感度，资产越稀缺 γ 越大；δ>0 价格向基本面回归的约束，初期 `β·C(t-τ2) ≫ δ·P(t)` 约束失效）。**延迟后的资金流入 `F(t-τ2)` 是价格上涨的核心动力。**
- **第三步（波动的延迟演化）**：`σ̇(t) = ε[σ0 - σ(t) - ζ·F(t-τ3) + η·F(t-τ3)²]`——
  `σ0` 基本面波动；`ζ>0` 资金涌入的「波动压制效应」（初期 F 增加使 σ 下降）；`η>0` 资金拥挤的「波动引爆效应」（F 过高时 F² 项主导使 σ 激增）。
  **波动先降后升，转折点由 `F(t-τ3) = ζ/η` 决定（拥挤阈值）。**
- **反馈强度全式**：`k = α·β·γ·(1/σ)`。
- **系统演化四阶段**：
  - **阶段1 初始稳健期（k<1，负反馈主导）**：资金流入规模小；`Ċ` 缓慢上升（预期与真实匹配）；`σ(t) ≈ σ0 - ζ·F(t)`（压制主导），SR 稳定；价格温和增长收敛于均衡点 `P* = γβC*/(γδ)`；**脆弱性极低**。
  - **阶段2 正反馈放大期（k>1）**：高夏普被广泛传播、资金流入突破初始阈值。三重延迟全在「帮倒忙」：`τ1` 使投资者用过去高夏普强化预期（`Ċ ≥ 0` 加速上升）；`τ2` 使「旧资金」仍在推价而「新资金」持续涌入（价涨→预期强化→资金更多→价格再涨循环）；`τ3` 使波动仍在下降、SR 进一步走高反向强化预期。
    数学特征：`Ṗ(t) ≈ γβ·P(t-τ1-τ2)/σ(t-τ1-τ3)`——σ 下降使分母变小，**Ṗ 增速越来越快（指数增长），系统远离均衡**；脆弱性快速累积，但被「价格上涨、波动下降」的表象掩盖。
  - **阶段3 脆弱性暴露期（k 非线性反转，波动激增）**：`F(t-τ3)` 突破拥挤阈值 `ζ/η`，波动「引爆效应」显现：`σ̇ > 0` 波动反转、σ 从低位快速飙升（流动性枯竭，一笔大额卖出就致价格大幅波动）；真实夏普率 `SR = P/σ` 急剧下降（σ 激增、P 因资金流入见顶停滞）；因 `τ1` 延迟投资者仍维持高预期 → 巨大「认知偏差」。
    **数学特征：系统出现分岔（稳定性突变），价格从「指数增长」转向「震荡加剧」，σ 非线性增长；脆弱性达到峰值。**
  - **阶段4 崩溃期（k < -1，负反馈主导）**：外部扰动（无风险利率上升/监管收紧/盈利不及预期）打破「认知幻觉」：`t-τ1` 期真实夏普率已大幅下跌 → `Ċ < 0`，预期断崖式下调；资金撤退延迟 `τ2` 使「旧资金」平仓压力与「新资金」撤离需求叠加（预期下降→资金卖出→价格下跌→预期更差）；σ 持续飙升进一步剧化下跌。
    数学特征：`Ṗ(t) ≈ γβ·P(t-τ1-τ2)/σ(t-τ1-τ3) < 0`——σ 激增使分母变大，**Ṗ 负向增速越来越快（崩溃加速）**；脆弱性集中爆发，`T_rec = ln20/λ` 大幅延长（λ 因流动性枯竭趋近 0）。
- **核心结论**：① 延迟效应（τ1τ2τ3）让「认知修正」滞后于「客体状态变化」，初期放大正反馈（k>1）推动价格脱离基本面；② 资金拥挤突破阈值后，波动的非线性反转（从「压制」到「引爆」）导致系统参数突变，反馈强度从正转负（k<-1）；③ 外部扰动触发负反馈循环，延迟效应再次放大下跌压力，最终导致系统崩溃。**延迟反馈动力系统的「滞后性」和「放大性」，让高夏普率资产的「稳健表象」在资金涌入后逐渐转化为「脆弱本质」。**

## 二、方法论骨架：三条独立链条

领会这 5 篇的关键，是认清它们**不是一套东西，而是三条可独立运行的链条**：

```
链一（结构层）  篇5 主涨段  ─→ 篇3 X段
                「谁在涨、涨到哪结束」        「中途回踩是桥梁还是转折」

链二（状态层）  篇4 极强/极弱状态机 + 级差体系
                「当前级别的『稳定性』有多高、能传递多远」

链三（资金层）  篇2 詹森不等式 ─→ 篇1 反身性/脆弱性
                「为什么抱团能推高、为什么切换必跌、脆弱性在哪里积累」
```

**三条链的接口**：
- 链二的「`N+2` 极强 → `N` 主涨段」正是**链一的输入**（篇5 的判定公式直接引用篇4 的极强状态）。
- 链一的「X 段 / 带结构回踩」是**链二的确认点**（`N` 级别 55 线得失效与否，决定主涨特征是否重新焕发）。
- 链三解释**链一/链二为什么有效**：抱团推高 `f(w)` 凸性 → 加速 → 脆弱性积累 → 切换时链一的结构崩塌、链二的状态反转。

| **双级差体系（A/B 两套）** | 现用 `5F/15F/60F/日/周` | **只有体系 A 的一部分**；体系 B（`1F-5F-30F-120F-双日-双周`）**缺失** |
| **抱团/切换的市值结论** | 无 | **全新维度**；`E[X]=Σwi²` 集中度可用成交额/持仓集中度近似，需数据评估 |
| **反身性 / 脆弱性** | 无 | **全新维度**；公式已补全（§1.6·B），`V_tail=1/ξ` 可用收益率数据估 GPD 尾指数，**先回测再谈融合** |
| **55 线各级别网格** | `layout_spec.py` 管排版，不涉及 | — |

> ⚠️ **回测已知结论（引用旁路文档）**：把「中轨层次 / 极强极弱 / 右侧标准 / 55线共振 / 刺破中轨」量化后回测 405 根日线，
> **方向维度整体无增量**（各分档涨跌概率多在 50%±10%）；**唯一有看空优势的是「持续极强」**（32.8%涨 vs 46.6%跌，但只是「1 日级别」动量衰竭）。
> 结论：**DRAGONBALL 是「关键位」工具，不是「方向」工具。**

## 四、「领会」层面的五条认识（本轮读完后形成的判断）

1. **它的强项是「关键位」而非「方向」。** 5 篇里所有可验证的规则，落点都是「**跌到哪条线、破了意味着什么**」——55 线、中轨、X 段终点。这解释了为什么回测里方向维度没增量，但关键位描述极准。

2. **「级别递进」是它的真正内核，不是 55 线本身。** 55 线只是刻度，真正的方法是：**破一级 → 升级一级 → 到下一级别的 55 线重新判**。篇5 的闭环「回踩 `N-1` 55 线 → 视作 `N-1` X 段 → 重新焕发 `N` 主涨特征 → 直到 `N` 中轨跌破」就是这条链的完整形态。

3. **「解除 ≠ 下跌」是反直觉、但被反复强调的一点。** 主涨特征解除后，原文给了**两条**路径（被压制 / 反抽突破再二次跌破），并且**只有二次跌破才算数**。这是对我们现有「跌破即转空」惯性最直接的一处纠偏。

4. **「稳定性」这个用词是刻意的。** 篇4 专门澄清 MACD 强弱**不是行情强弱**。这实际上把 MACD 从「方向指标」重新定义成了「**趋势持续性的度量**」——这与我们现有把 MACD 当动能/背离依据的用法，是**同源但不同语义**的。融合时需要小心：**不能把两套语义混在一个字段里**（这条与本项目既有的「出参给人看、返回值给机器用，别拿混」是同一类坑）。

5. **篇2/篇1 是「为什么」——公式已补全，且出现了可计算量（2026-09-24 晚更新）。** 詹森不等式的推导链（§1.6·A）完整落地：`E[X]=Σwi²` 就是**集中度**的数学表达，`R ≥ f(E[X])` 说明总收益率下限由集中度决定——这给「主线涨、非主线跌」「切换必跌」给出了严格证明。篇1 的公式链（§1.6·B）里出现三个**潜在可计算量**：① `V_tail = 1/ξ`（GPD 尾指数，标准 EVT 方法，用收益率数据即可拟合）；② 拥挤阈值 `F = ζ/η`（波动先压后引的转折点）；③ 四阶段状态机（k<1 稳健 → k>1 正反馈 → 分岔 → k<-1 崩溃，可用「波动率变化 + 价格动量 + 资金流」做定性映射）。**但仍然：先回测验证有没有预测增量，验证之前一律不进打分公式**——方向维度无增量的回测教训（旁路文档 §五）同样适用于链三。
