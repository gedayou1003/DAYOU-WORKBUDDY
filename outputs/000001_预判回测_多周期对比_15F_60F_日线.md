# 000001 预判回测 · 多周期对比（15F / 60F / 日线）

> 用各自最大可取 K 线根数，统一 v4 预判规则（方向量化打分 + 方向不明 + 区间带 + BOLL 兜底），无未来函数，涨红跌绿

## 一、三周期对比

| 指标 | 15F 版（1 个月） | 60F 版（10 个月） | 日线版（2.5 年） |
|---|---|---|---|
| **样本（交易日）** | 19 | 188 | **581** |
| 方向命中率 | 36.8% | **47.3%** | 44.1% |
| 方向相反率 | 36.8% | **27.7%** | 29.8% |
| 方向规避率 | 21.1% | 18.6% | 17.9% |
| 区间覆盖率 | 31.6% | 42.0% | **59.9%** |
| 支撑守住率 | 68.4% | 73.9% | **80.7%** |
| 压力守住率 | 47.4% | 67.0% | **79.2%** |

## 二、核心发现

### 1. 周期越长，方向判断越准
- 方向相反率：15F 版 36.8% → 60F 版 **27.7%** → 日线版 29.8%
- 15F 版样本只有 19 个，误差大；60F 版 188 个、日线版 581 个，结论可靠
- **本质**：日线/周线的买卖点信号比 15F/5F 稳定（噪音少），小级别信号在短线波动中更易失效

### 2. 支撑/压力在长周期下更"扛得住"
- 支撑守住率：68.4% → 73.9% → **80.7%**（日线版近 8 成守住）
- 压力守住率：47.4% → 67.0% → **79.2%**
- 区间覆盖率：31.6% → 42.0% → **59.9%**
- **本质**：日线 BOLL 上下轨 + 日线买卖点的"带宽"远大于 15F 级别，不容易被单日噪音穿透

### 3. v4 规则在长周期下验证有效
- 日线版（581 样本）方向相反率 29.8%，明显好于原版 v1 的 52.6%
- 说明「方向不明」状态 + 趋势因子 + 区间带 + BOLL 兜底这套补救，在长周期同样成立，不是 1 个月样本的偶然

## 三、对生产模型的关键启示 ⚠️

**方向判断应以大级别（日线/周线）为主，小级别（15F/5F）只用于"找精确买卖点位"，不用于"定方向"。**

回测证据：日线版（只用日线+周线定方向）相反率 29.8%，反而比 15F 版（含 15F 定方向）的 36.8% 更低——**15F 信号在方向判断里是"噪音"而非"增益"**。

这印证了缠论经典原则："周线/日线定方向，60/15/5 分钟找点位"。

**当前 v4 规则里 15F 在方向打分中权重为 ±1**，这个回测提示可以进一步考虑：**方向打分只用日线/周线（±2），60F/15F 不参与方向打分、只用于找支撑压力点位**。但这是下一步优化，需你在 60F/日线长样本下再确认后再动。

## 四、诚实说明

1. 日线版 581 个交易日、60F 版 188 个，统计显著性远高于之前的 19 个，结论更可信。
2. 即便如此，方向相反率仍有 28~30%，缠论买卖点在趋势反转期的固有滞后仍未根治（这是结构类信号的局限，需"变盘信号前置预警"逐步改善）。
3. 三个版本的预判规则完全一致（v4），差异只在周期组合和数据区间，因此差异可归因于"周期级别"本身。
